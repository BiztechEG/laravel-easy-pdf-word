# تقرير جدولي

تقرير جدولي لأي قائمة من الصفوف يطلبها أحد في الشركة ملفاً: المبيعات حسب الفرع، أو الطلبات، أو المخزون، أو الحضور. يأخذ القالب `report` الأعمدة التي تختارها، ويضيف صف الإجمالي وبطاقات الملخص، ويكرر رأس الجدول في كل صفحة.

## متى تستخدمه {#when-to-use}

- المبيعات الشهرية حسب الفرع أو مندوب المبيعات لاجتماع الإدارة.
- قوائم الطلبات أو الفواتير أو المدفوعات لفترة معينة، للمحاسب.
- أرصدة المخزون حسب المستودع، أو قائمة أسعار حسب الفئة.
- تقارير الحضور والإجازات لقسم الموارد البشرية.
- زر "تصدير" على أي جدول في لوحة الإدارة، يعطي الصفوف نفسها ملف PDF أو Word.

## مثال سريع {#example}

مرّر العنوان والأعمدة والصفوف:

```php
use BiztechEG\EasyPdfWord\Facades\Doc;

$report = Doc::template('report', [
    'title' => 'تقرير المبيعات الشهري',
    'subtitle' => 'الفترة من 1 سبتمبر حتى 30 سبتمبر 2026',
    'columns' => [
        ['key' => 'branch', 'label' => 'الفرع'],
        ['key' => 'manager', 'label' => 'المدير'],
        ['key' => 'orders', 'label' => 'عدد الطلبات', 'format' => 'number', 'decimals' => 0],
        ['key' => 'revenue', 'label' => 'الإيرادات (ج.م)', 'format' => 'number'],
        ['key' => 'growth', 'label' => 'النمو %', 'format' => 'number', 'decimals' => 1],
    ],
    'rows' => [
        ['branch' => 'القاهرة - مدينة نصر', 'manager' => 'سارة إبراهيم', 'orders' => 1240, 'revenue' => 486500.75, 'growth' => 12.4],
        ['branch' => 'الجيزة - الدقي', 'manager' => 'محمد علي', 'orders' => 980, 'revenue' => 371200, 'growth' => 8.1],
        ['branch' => 'الإسكندرية - سموحة', 'manager' => 'Omar Khaled', 'orders' => 765, 'revenue' => 290340.5, 'growth' => -2.3],
        ['branch' => 'المنصورة', 'manager' => 'هبة سمير', 'orders' => 410, 'revenue' => 150875, 'growth' => 4.7],
    ],
    'sum' => ['orders', 'revenue'],
    'summary' => [
        'إجمالي الإيرادات' => '1,298,916.25 ج.م',
        'أعلى فرع' => 'مدينة نصر',
        'عدد الفروع' => '4',
    ],
    'generated_at' => '2026-10-08 10:30',
])->locale('ar');
```

ثم أعِد الملف الذي تحتاجه:

::: code-group

```php [PDF]
return $report->pdf()->download('sales-2026-09.pdf');
```

```php [Word]
return $report->word()->download('sales-2026-09.docx');
```

:::

النتيجة صفحة A4 واحدة، مثل المعاينة أعلاه:

- العنوان والعنوان الفرعي، وفي الجانب الآخر اسم الشركة وتاريخ الإنشاء: 2026/10/08 10:30؛
- ثلاث بطاقات ملخص بالعناوين والقيم الواردة في `summary`؛
- الجدول، وفيه عمود `#` يرقّم الصفوف من 1، والأعمدة الرقمية محاذاة إلى نهاية السطر، والقيمة -2.3 بإشارة السالب في مكانها الصحيح؛
- صف الإجمالي، وفيه 3,395 طلباً و1,298,916.25 إيرادات؛
- تذييل فيه عنوان التقرير وصفحة 1 من 1.

## الحقول {#fields}

يجري التحقق من البيانات قبل رسم أي شيء. ويمكن ترك الحقول التي لها قيمة افتراضية.

| الحقل | مطلوب | النوع أو القيم | القيمة الافتراضية | الوظيفة |
| --- | --- | --- | --- | --- |
| `title` | نعم | نص | | عنوان التقرير، في الأعلى وفي التذييل. |
| `subtitle` | لا | نص | | سطر رمادي تحت العنوان، مثل الفترة. |
| `columns` | نعم | قائمة أو مصفوفة مفاتيح، عمود واحد على الأقل | | الأعمدة المعروضة بالترتيب. انظر [الأعمدة](#columns). |
| `rows` | نعم، ويمكن أن تكون فارغة | قائمة مصفوفات أو models أو كائنات | | الصفوف. والقائمة الفارغة تطبع لا توجد بيانات. |
| `sum` | لا | قائمة مفاتيح أعمدة | فارغة | الأعمدة التي تُجمع في الصف الأخير. |
| `summary` | لا | مصفوفة عنوان => قيمة | فارغة | بطاقات الملخص فوق الجدول، بالترتيب. |
| `generated_at` | لا | تاريخ ووقت | الآن | يُطبع في الأعلى بعنوان تاريخ الإنشاء، بالشكل `2026/10/08 10:30`. |

ويقبل كل عمود الخيارات التالية:

| الخيار | القيمة الافتراضية | الوظيفة |
| --- | --- | --- |
| `key` | مفتاح المصفوفة | مكان القيمة في كل صف. والنقاط تصل إلى البيانات المتداخلة: `customer.name`. |
| `label` | المفتاح | عنوان العمود. |
| `format` | نص | `number` أو `money`: فواصل الآلاف وعدد خانات `decimals`. و`date`: يُطبع بالشكل `2026/09/03`. وغير ذلك: القيمة نصاً. |
| `decimals` | `2` | الخانات العشرية للتنسيقين `number` و`money` (بحد أقصى 10). |
| `align` | `end` للتنسيقين `number` و`money`، و`start` لغيرهما | `start` أو `end` أو `center`. وفي العربية `start` هو الجانب الأيمن. |

التنسيق `money` مثل `number` تماماً ولا يضيف رمز عملة، فاكتب العملة في العنوان، كما في الإيرادات (ج.م).

ويحسب القالب أيضاً `totals` من `sum`، فلا تمررها.

### قيم الهوية {#theme}

| مفتاح الهوية | مكان ظهوره |
| --- | --- |
| `company.name` | الركن العلوي، مقابل العنوان. |
| `primary` | العنوان، وصف رأس الجدول، وقيم الملخص، والخط فوق الإجمالي. |
| `muted` | العنوان الفرعي، واسم الشركة، وتاريخ الإنشاء، وعناوين الملخص. |
| `border` | خطوط الصفوف وحدود بطاقات الملخص. |

لا شعار ولا ترويسة في التقرير، فهو للقراءة كبيانات. انسخ القالب (انظر [تخصيص القالب](#customise)) إن احتجت إلى ذلك.

## الأنواع والخيارات {#options}

### الأعمدة {#columns}

اكتب كل عمود مصفوفة كاملة كما في المثال، أو استخدم الصيغة المختصرة `key => label` للأعمدة النصية. ويمكن الجمع بين الصيغتين، والمصفوفة الكاملة التي ليس فيها `key` تأخذ مفتاحها في المصفوفة:

```php
'columns' => [
    'number' => 'رقم الطلب',
    'customer.name' => 'العميل',
    'created_at' => ['label' => 'التاريخ', 'format' => 'date'],
    'total' => ['label' => 'الإجمالي (ج.م)', 'format' => 'money'],
],
```

### صفوف من قاعدة بياناتك {#rows}

يقبل `rows` المصفوفات، وEloquent models، والـ collections، ونتائج الـ query builder. وتتحول الـ models إلى مصفوفات مع علاقاتها المحمّلة، فالمفتاح ذو النقطة مثل `customer.name` يقرأ من العلاقة:

```php
use App\Models\Order;
use BiztechEG\EasyPdfWord\Facades\Doc;

$report = Doc::template('report', [
    'title' => 'طلبات شهر سبتمبر',
    'columns' => [
        'number' => 'رقم الطلب',
        'customer.name' => 'العميل',
        'created_at' => ['label' => 'التاريخ', 'format' => 'date'],
        'total' => ['label' => 'الإجمالي (ج.م)', 'format' => 'money'],
    ],
    'rows' => Order::with('customer')->orderBy('created_at')->get(),
    'sum' => ['total'],
])->locale('ar');
```

أعطِ أعمدة التواريخ `'format' => 'date'`: فالـ model يحوّل تواريخه إلى نصوص طويلة مثل `2026-09-03T10:00:00.000000Z`، والتنسيق `date` يطبعها بالشكل `2026/09/03`. وفي الأعمدة النصية تُطبع القيمة `true` بالعلامة ✓، والمصفوفة بصيغة JSON.

### صف الإجمالي {#totals}

يحدد `sum` مفاتيح الأعمدة التي تُجمع. يأخذ كل إجمالي تنسيق عموده، وتُكتب كلمة الإجمالي / Total في العمود الأول، ما لم يكن العمود الأول نفسه من الأعمدة المجموعة. والقيم المكتوبة نصاً تُقرأ كما تبدو: `"1,240"` تُحسب 1240، وتُقرأ الأرقام العربية أيضاً.

### بطاقات الملخص {#summary}

الحقل `summary` مصفوفة عنوان => قيمة، وكل زوج يصبح بطاقة فوق الجدول، متجاورة بالترتيب. وتُطبع القيم كما تمررها، فنسّقها أولاً: `'1,298,916.25 ج.م'`.

### صفحات بالعرض {#landscape}

الجداول العريضة تتسع أكثر على صفحة بالعرض:

```php
return $report->landscape()->pdf()->download('sales-2026-09.pdf');
```

ويتبع ملف Word الإعداد نفسه. انظر [إعدادات الصفحة](/ar/guide/page-settings) لمقاسات الورق والهوامش.

### رأس الجدول في كل صفحة {#repeated-header}

حين يمتد الجدول إلى أكثر من صفحة، يتكرر صف رأسه أعلى كل صفحة، ويعرض التذييل العنوان ورقم الصفحة، مثل صفحة 2 من 5. ويستمر ترقيم الصفوف عبر الصفحات، وتتناوب ألوانها لتسهل قراءتها.

### التقارير الكبيرة {#large}

يحتفظ mPDF بالجدول كله في الذاكرة أثناء ترتيبه، لذا يحتاج التقرير الذي يزيد على بضع مئات من الصفوف إلى رفع `memory_limit` للطلب أو الـ job الذي ينشئه، أو إلى محرك Chromium الذي يحتاج إلى ذاكرة أقل بكثير. انظر [محركات PDF](/ar/guide/engines).

## ملف Word {#word}

للتقرير ملف `pdf.html.php` لملف PDF، وملف `word.php` منفصل لملف Word، ويُبنى الاثنان من البيانات نفسها. يحمل ملف Word رأس العنوان نفسه، وبطاقات الملخص، والصفوف المرقّمة متناوبة الألوان، وصف الإجمالي، ويُعلَّم صف الرأس ليتكرر في كل صفحة في Word أيضاً. وتُنسَّق الأرقام بالطريقة نفسها، ويتبع اتجاه الصفحة `->landscape()`. ويصبح التذييل سطراً من نص رمادي صغير مع أرقام صفحات Word.

ومن يريد إضافة تعليق أو رسم بياني يستطيع ذلك في ملف Word. وملفات Word تحتاج إلى الحزمة `phpoffice/phpword`؛ انظر [ملفات Word](/ar/guide/word).

## تخصيص القالب {#customise}

```bash
php artisan doc:template report --as=my-report
```

ينسخ هذا الأمر القالب إلى `resources/doc-templates/my-report/`:

- `template.php`: الحقول والقيم الافتراضية وإعدادات الصفحة؛ أضف `'orientation' => 'landscape'` لتصبح كل التقارير بالعرض؛
- `pdf.html.php`: تخطيط PDF وتنسيقات CSS؛
- `word.php`: تخطيط ملف Word؛
- `footer.html.php`: التذييل بالعنوان وأرقام الصفحات؛
- `lang/ar.php` و`lang/en.php`: العناوين الإجمالي، ولا توجد بيانات، وتاريخ الإنشاء.

عدّل `pdf.html.php` و`word.php` معاً ليبقى الملفان متشابهين. واستخدم النسخة عبر `Doc::template('my-report', $data)`. انظر [قوالبك الخاصة](/ar/guide/custom-templates).
