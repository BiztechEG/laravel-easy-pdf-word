# خطاب رسمي

خطاب رسمي على ورق الشركة، من النوع الذي يرسله مدير أو قسم الموارد البشرية إلى عميل أو بنك أو سفارة أو جهة حكومية. يضيف القالب `letter` رقم الخطاب، والتاريخين الميلادي والهجري، وسطر الموضوع، والتوقيع، والختم، وقائمة الجهات التي تُرسل إليها صورة.

## متى تستخدمه {#when-to-use}

- خطابات العروض والتغطية المرسلة إلى العملاء، كما في المثال أعلاه.
- خطابات الراتب وإفادات العمل (شهادة لمن يهمه الأمر) التي يقدّمها الموظف إلى بنك أو سفارة.
- الخطابات الموجهة إلى جهات حكومية تنتظر رقماً صادراً وتاريخاً هجرياً، كما هو شائع في السعودية.
- الإخطارات إلى الموردين أو المستأجرين: تذكير بالسداد، أو تجديد عقد، أو إنهاؤه.
- المذكرات الداخلية إلى مدير، مع صورة إلى أقسام أخرى.

## مثال سريع {#example}

مرّر بيانات الخطاب:

```php
use BiztechEG\EasyPdfWord\Facades\Doc;

$letter = Doc::template('letter', [
    'reference' => 'ص/2026/417',
    'date' => '2026-10-08',
    'recipient' => [
        'name' => 'المهندس أحمد عبد الرحمن',
        'title' => 'مدير إدارة تقنية المعلومات',
        'organization' => 'مؤسسة النور للتجارة',
    ],
    'subject' => 'عرض تنفيذ نظام إدارة المستندات',
    'body' => "إشارة إلى اجتماعنا المنعقد بتاريخ 1 أكتوبر 2026، يسعدنا أن نقدم لكم عرضنا لتنفيذ نظام إدارة المستندات الإلكترونية، والذي يشمل إصدار الفواتير والخطابات والتقارير باللغتين العربية والإنجليزية.\n\n"
        ."تبلغ مدة التنفيذ 45 يوم عمل من تاريخ التعاقد، ويتضمن العرض تدريب فريقكم والدعم الفني لمدة 12 شهراً.\n\n"
        .'نأمل أن ينال عرضنا رضاكم، ونحن على استعداد للرد على أي استفسارات.',
    'sender' => [
        'name' => 'عمرو محمد',
        'title' => 'المدير التنفيذي',
    ],
    'cc' => ['الإدارة المالية', 'الملف العام'],
])->locale('ar');
```

ثم أعِد الملف الذي تحتاجه:

::: code-group

```php [PDF]
return $letter->pdf()->download('letter-417.pdf');
```

```php [Word]
return $letter->word()->download('letter-417.docx');
```

:::

النتيجة صفحة A4 واحدة، مثل المعاينة أعلاه:

- الترويسة: اسم الشركة وعنوانها من الهوية، والشعار، وخط باللون الأساسي؛
- الرقم ص/2026/417، والتاريخ 2026/10/08، والموافق 27 ربيع الآخر 1448 هـ، وهو التاريخ الهجري المحسوب من `date`؛
- المرسل إليه: السيد/ مدير إدارة تقنية المعلومات، ثم الاسم بخط عريض، ثم الجهة؛
- الموضوع في المنتصف: الموضوع: عرض تنفيذ نظام إدارة المستندات، ثم التحية (تحية طيبة وبعد،)، وثلاث فقرات مضبوطة الطرفين، ثم الختام (وتفضلوا بقبول فائق الاحترام والتقدير،)؛
- صفة المرسل واسمه، مع مساحة للتوقيع؛
- صورة إلى: وقائمة الجهات، ثم تذييل فيه رقم الصفحة.

## الحقول {#fields}

يجري التحقق من البيانات قبل رسم أي شيء. ويمكن ترك الحقول التي لها قيمة افتراضية.

| الحقل | مطلوب | النوع أو القيم | القيمة الافتراضية | الوظيفة |
| --- | --- | --- | --- | --- |
| `reference` | لا | نص | | رقم الخطاب الصادر (الرقم / Ref.). |
| `date` | نعم | تاريخ | | تاريخ الخطاب بالشكل `2026/10/08`، ومنه يُحسب التاريخ الهجري. |
| `show_hijri` | لا | `true` أو `false` | `true` | يطبع التاريخ الهجري تحت الميلادي في الخطابات العربية. |
| `recipient.name` | نعم | نص | | اسم المرسل إليه، بخط عريض. |
| `recipient.title` | لا | نص | | منصب المرسل إليه، ويُطبع فوق الاسم بالعربية بالشكل: السيد/ مدير إدارة ... |
| `recipient.organization` | لا | نص | | جهة المرسل إليه، تحت الاسم. |
| `subject` | نعم | نص | | سطر الموضوع في المنتصف: الموضوع: ... / Subject: ... |
| `greeting` | لا | نص | تحية طيبة وبعد، / Dear Sir/Madam, | السطر الذي يسبق نص الخطاب. |
| `body` | نعم | نص أو قائمة فقرات | | نص الخطاب. في النص الواحد، يبدأ السطر الفارغ فقرة جديدة. |
| `closing` | لا | نص | وتفضلوا بقبول فائق الاحترام والتقدير، / Yours sincerely, | السطر الذي يلي نص الخطاب. |
| `sender.name` | نعم | نص | | اسم الموقّع، بخط عريض. |
| `sender.title` | لا | نص | | منصب الموقّع، فوق التوقيع. |
| `signature` | لا | مسار صورة أو data URI | | صورة التوقيع، بين المنصب والاسم. |
| `stamp` | لا | مسار صورة أو data URI | | ختم الشركة، بجوار التوقيع. |
| `cc` | لا | قائمة نصوص | فارغة | صورة إلى (Copy to)، كل جهة في سطر. |

### قيم الهوية {#theme}

| مفتاح الهوية | مكان ظهوره |
| --- | --- |
| `company.name` | الترويسة، بخط عريض وباللون الأساسي. |
| `company.address` | تحت اسم الشركة، وفي التذييل. |
| `company.phone` | في التذييل، من اليسار إلى اليمين. |
| `company.email` | في التذييل، من اليسار إلى اليمين. |
| `logo` | الجانب الآخر من الترويسة، بارتفاع 18 مم. |
| `primary` | اسم الشركة والخط تحت الترويسة. |
| `muted` | عناوين خانات الرقم والتاريخ، وعنوان صورة إلى. |

ترويسة مع بيانات الاتصال كاملة في التذييل:

```php
Doc::template('letter', $data)
    ->theme([
        'logo' => public_path('images/logo.png'),
        'company' => [
            'name' => 'شركة بيزتك للحلول البرمجية',
            'address' => '15 شارع التحرير، الدقي، الجيزة',
            'phone' => '+20 2 3333 4444',
            'email' => 'info@biztech.example',
        ],
    ])
    ->locale('ar')
    ->pdf();
```

## الأنواع والخيارات {#options}

### رقم الخطاب {#reference}

يُطبع `reference` كما تمرره، في خانة الرقم بجوار التاريخين. وكثيراً ما تستخدم الخطابات بادئة وشرطات مائلة، مثل ص/2026/417 (ص للصادر). وإذا تركته لا يُطبع صفه.

### التاريخ الهجري {#hijri}

في الخطابات العربية يضيف القالب التاريخ الهجري (تقويم أم القرى) المقابل لـ `date` تحت الميلادي، بعنوان الموافق: فيصبح 2026-10-08 هو 27 ربيع الآخر 1448 هـ. ويحتاج ذلك إلى إضافة PHP المسماة `intl`، ومن دونها يُحذف الصف. ولا يظهر إلا في المستندات التي تُكتب من اليمين إلى اليسار، فلا يظهر في الخطابات الإنجليزية. ولحذفه من خطاب عربي مرّر `'show_hijri' => false`. ومع `->numerals('arabic')` يُكتب ٢٧ ربيع الآخر ١٤٤٨ هـ. المزيد في [دعم اللغة العربية](/ar/guide/arabic).

### نص الخطاب والتحية والختام {#body}

يقبل `body` نصاً واحداً أو قائمة فقرات. في النص الواحد افصل الفقرات بسطر فارغ (`\n\n`). والقائمة أسهل حين تأتي الفقرات من الكود، كما في إفادة العمل التالية:

```php
Doc::template('letter', [
    'date' => '2026-10-08',
    'recipient' => ['name' => 'السادة/ البنك الأهلي المصري', 'organization' => 'فرع الدقي'],
    'subject' => 'إفادة عمل',
    'body' => [
        'نود إفادتكم بأن السيدة سارة محمود عبد الله تعمل لدى شركتنا بوظيفة مطورة برمجيات أولى منذ 1 مارس 2022.',
        'وقد أُعطيت لها هذه الإفادة بناءً على طلبها دون أدنى مسؤولية على الشركة.',
    ],
    'show_hijri' => false,
    'greeting' => 'تحية طيبة وبعد،،،',
    'closing' => 'وتفضلوا بقبول وافر الاحترام،',
    'sender' => ['name' => 'منى سامي', 'title' => 'مدير الموارد البشرية'],
])->locale('ar')->pdf();
```

يحل `greeting` و`closing` محل السطرين الافتراضيين. والفقرات مضبوطة الطرفين في ملف PDF وملف Word معاً.

### المرسل إليه {#recipient}

خانة المرسل إليه تصل إلى ثلاثة أسطر: `recipient.title` (بعد السيد/ بالعربية)، ثم `recipient.name` بخط عريض، ثم `recipient.organization`. وحين تكتب إلى جهة لا إلى شخص، ضع صيغة المخاطبة كاملة في `name`، مثل السادة/ البنك الأهلي المصري أعلاه، واترك `title`.

### التوقيع والختم {#signature-stamp}

يقبل `signature` و`stamp` صورة: مساراً أو data URI. يأتي التوقيع بين منصب المرسل واسمه، ويأتي الختم بجواره:

```php
$data['signature'] = storage_path('app/signatures/ceo.png');
$data['stamp'] = storage_path('app/signatures/stamp.png');
```

لا تُقرأ الصور المحلية إلا من المجلدات المسموح بها في الإعدادات (`public` و`storage/app` و`resources` افتراضياً)، ولا تُقرأ الروابط إلا إذا فُعّلت الصور البعيدة. والصورة غير المسموح بها تُتخطى دون أي خطأ، فراجع النتيجة مرة. واستخدم صورة PNG بخلفية شفافة. انظر [الصور](/ar/guide/images).

::: warning تنبيه
احفظ ملفات التوقيع والختم خارج المجلد `public`، حيث يستطيع أي شخص تنزيلها. والمجلد `storage/app` مكان أكثر أماناً.
:::

### صورة إلى {#cc}

يحدد `cc` الجهات التي تتلقى صورة من الخطاب، كل جهة في سطر تحت صورة إلى:، بعد التوقيع.

### الترويسة والتذييل {#letterhead}

الترويسة والتذييل يأتيان من الهوية، فتبدو كل الخطابات الصادرة من تطبيقك متشابهة. يجمع التذييل `company.address` و`company.phone` و`company.email` بينها الفاصل `|` ويضيف رقم الصفحة، ويتخطى القيم الفارغة.

## ملف Word {#word}

للخطاب ملف `pdf.blade.php` لملف PDF، وملف `word.php` منفصل لملف Word، ويُبنى الاثنان من البيانات نفسها. يحمل ملف Word الأجزاء نفسها بالترتيب نفسه: الترويسة وتحتها خط، وخانة الرقم والتاريخ (بقاعدة التاريخ الهجري نفسها)، والمرسل إليه، والموضوع، والفقرات المضبوطة الطرفين، والختم والتوقيع، وصورة إلى. ويصبح التذييل سطراً من نص رمادي صغير مع أرقام صفحات Word.

ملف Word مفيد حين يحتاج الخطاب إلى تعديل أخير قبل طباعته وتوقيعه باليد. وملفات Word تحتاج إلى الحزمة `phpoffice/phpword`؛ انظر [ملفات Word](/ar/guide/word).

## تخصيص القالب {#customise}

```bash
php artisan doc:template letter --as=my-letter
```

ينسخ هذا الأمر القالب إلى `resources/doc-templates/my-letter/`:

- `template.php`: الحقول والقيم الافتراضية، مثل `'show_hijri' => false`؛
- `pdf.blade.php`: تخطيط PDF وتنسيقات CSS؛
- `word.php`: تخطيط ملف Word؛
- `footer.blade.php`: تذييل بيانات الاتصال؛
- `lang/ar.php` و`lang/en.php`: العناوين، والتحية والختام الافتراضيان.

عدّل `pdf.blade.php` و`word.php` معاً ليبقى الملفان متشابهين. واستخدم النسخة عبر `Doc::template('my-letter', $data)`. انظر [قوالبك الخاصة](/ar/guide/custom-templates).
