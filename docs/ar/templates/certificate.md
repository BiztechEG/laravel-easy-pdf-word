# شهادة

شهادة إتمام أو حضور أو مشاركة أو شكر وتقدير، يصدرها مركز تدريب أو أكاديمية أو مدرسة أو شركة لشخص بعينه. يطبع القالب `certificate` الشهادة على صفحة A4 بالعرض داخل إطار، مع ما يصل إلى ثلاثة توقيعات، ورمز QR يقود إلى صفحة يتحقق منها أي شخص من صحة الشهادة.

## متى تستخدمه {#when-to-use}

- شهادات الإتمام في نهاية دورة تدريبية، مع التواريخ وعدد الساعات والتقدير.
- شهادات الحضور لورشة عمل أو ندوة أو يوم من أيام مؤتمر.
- شهادات المشاركة للمتحدثين أو المتطوعين أو فرق المسابقات.
- شهادات الشكر والتقدير للموظفين أو الشركاء أو الرعاة.
- صفحة تحقق يمسح فيها صاحب العمل رمز QR ليتأكد من أن الشهادة أصلية.

## مثال سريع {#example}

مرّر بيانات الشهادة:

```php
use BiztechEG\EasyPdfWord\Facades\Doc;

$certificate = Doc::template('certificate', [
    'type' => 'completion',
    'gender' => 'female',
    'number' => 'CRT-2026-00731',
    'date' => '2026-10-08',
    'recipient' => 'سارة محمود عبد الله',
    'course' => 'تطوير تطبيقات الويب باستخدام Laravel',
    'from' => '2026-09-06',
    'to' => '2026-10-01',
    'hours' => 40,
    'grade' => 'امتياز',
    'issuer' => 'أكاديمية بيزتك للتدريب',
    'signatures' => [
        ['name' => 'م. أحمد عبد الرحمن', 'title' => 'المدرب'],
        ['name' => 'عمرو محمد', 'title' => 'مدير الأكاديمية'],
    ],
    'verify_url' => 'https://academy.example.com/certificates/CRT-2026-00731',
])->locale('ar');
```

ثم أعِد الملف الذي تحتاجه:

::: code-group

```php [PDF]
return $certificate->pdf()->download('CRT-2026-00731.pdf');
```

```php [Word]
return $certificate->word()->download('CRT-2026-00731.docx');
```

:::

النتيجة صفحة A4 واحدة بالعرض داخل إطار مزدوج، مثل المعاينة أعلاه:

- تاريخ الإصدار ورقم الشهادة في ركن، والجهة المانحة في المنتصف، ورمز QR مع عبارة امسح الرمز للتحقق من الشهادة في الركن الآخر؛
- العنوان شهادة إتمام، ثم تُمنح هذه الشهادة إلى، واسم المتدربة بخط كبير؛
- لإتمامها بنجاح (بصيغة المؤنث لأن `gender` هي `female`)، ثم اسم الدورة؛
- السطر: خلال الفترة من 2026/09/06 إلى 2026/10/01، بعدد 40 ساعة تدريبية، بتقدير امتياز؛
- خطان للتوقيع، وتحت كل منهما الاسم والصفة.

## الحقول {#fields}

يجري التحقق من البيانات قبل رسم أي شيء. ويمكن ترك الحقول التي لها قيمة افتراضية.

| الحقل | مطلوب | النوع أو القيم | القيمة الافتراضية | الوظيفة |
| --- | --- | --- | --- | --- |
| `type` | نعم | `completion` أو `attendance` أو `participation` أو `appreciation` | `completion` | نوع الشهادة، ويحدد العنوان والصياغة. انظر [أنواع الشهادات](#kinds). |
| `gender` | نعم | `male` أو `female` | `male` | جنس صاحب الشهادة، للصياغة العربية: لإتمامه أو لإتمامها. |
| `number` | لا | نص | | رقم الشهادة في الركن العلوي، من اليسار إلى اليمين. |
| `date` | نعم | تاريخ | | تاريخ الإصدار. |
| `recipient` | نعم | نص | | اسم صاحب الشهادة، بخط كبير عريض. |
| `course` | نعم | نص | | الدورة أو الفعالية أو الإسهام، باللون الأساسي. |
| `details` | لا | نص | | سطر إضافي تحت تفاصيل الدورة. |
| `from` | لا | تاريخ | | أول أيام الدورة. |
| `to` | لا | تاريخ، في يوم `from` أو بعده | | آخر أيام الدورة. |
| `hours` | لا | رقم أكبر من 0 | | عدد الساعات التدريبية، بصيغة العدد العربية الصحيحة. اتركه إن لم تكن هناك ساعات. |
| `grade` | لا | نص | | التقدير: بتقدير امتياز. |
| `issuer` | لا | نص | `company.name` من الهوية | الجهة المانحة، أعلى المنتصف. |
| `signatures` | لا | قائمة، 3 على الأكثر | فارغة | التوقيعات، متجاورة. |
| `signatures.*.name` | نعم | نص | | اسم الموقّع، بخط عريض تحت الخط. |
| `signatures.*.title` | لا | نص | | صفة الموقّع، تحت الاسم. |
| `verify_url` | لا | نص | | رابط يُطبع رمز QR للتحقق من الشهادة. |

### قيم الهوية {#theme}

| مفتاح الهوية | مكان ظهوره |
| --- | --- |
| `company.name` | الجهة المانحة، إذا كان `issuer` فارغاً. |
| `logo` | فوق الجهة المانحة، بارتفاع 16 مم. |
| `primary` | الإطار المزدوج، والعنوان، واسم الدورة، والخط تحت اسم صاحب الشهادة. |
| `muted` | نص الأركان، وسطر التفاصيل، وخطوط التوقيع. |

## الأنواع والخيارات {#options}

### أنواع الشهادات {#kinds}

| `type` | العنوان بالعربية | العنوان بالإنجليزية | عبارة البداية |
| --- | --- | --- | --- |
| `completion` | شهادة إتمام | Certificate of Completion | تُمنح هذه الشهادة إلى / This certificate is awarded to |
| `attendance` | شهادة حضور | Certificate of Attendance | تُمنح هذه الشهادة إلى / This certificate is awarded to |
| `participation` | شهادة مشاركة | Certificate of Participation | تُمنح هذه الشهادة إلى / This certificate is awarded to |
| `appreciation` | شهادة شكر وتقدير | Certificate of Appreciation | تُقدَّم هذه الشهادة مع خالص الشكر والتقدير إلى / This certificate is presented with sincere thanks to |

عبارات البداية العربية مبنية للمجهول (تُمنح، تُقدَّم)، فتصح سواء كانت الجهة المانحة شركة أو معهداً أو جامعة.

### الصياغة حسب الجنس {#gender}

تتغير الكلمات بعد الاسم في العربية حسب جنس صاحب الشهادة، ويختارها القالب من `type` و`gender`:

| `type` | `male` | `female` | بالإنجليزية |
| --- | --- | --- | --- |
| `completion` | لإتمامه بنجاح | لإتمامها بنجاح | for successfully completing |
| `attendance` | لحضوره | لحضورها | for attending |
| `participation` | لمشاركته في | لمشاركتها في | for participating in |
| `appreciation` | تقديراً لجهوده المتميزة في | تقديراً لجهودها المتميزة في | in appreciation of an outstanding contribution to |

القيمة الافتراضية لـ `gender` هي `male`، فمرّرها لكل شخص حين تصدر الشهادات دفعة واحدة.

### التواريخ والساعات والتقدير {#facts}

يجمع السطر تحت اسم الدورة ما تمرره من:

- `from` و`to`: خلال الفترة من 2026/09/06 إلى 2026/10/01؛
- أحدهما فقط، لفعالية يوم واحد: بتاريخ 2026/10/01؛
- `hours` بصيغة العدد العربية: بعدد ساعة تدريبية واحدة (1)، بعدد ساعتين تدريبيتين (2)، بعدد 6 ساعات تدريبية (من 3 إلى 10)، بعدد 40 ساعة تدريبية (11 فأكثر، والأعداد العشرية مثل 7.5). وبعد المائة تحكم آخر خانتين، فالعدد 103 يأتي معه ساعات والعدد 140 يأتي معه ساعة. وبالإنجليزية: one training hour، 40 training hours؛
- `grade`: بتقدير امتياز.

إذا لم يُمرَّر أي منها حُذف السطر. ويضيف `details` سطراً آخر تحته، مثل اسم البرنامج التدريبي.

### الجهة المانحة {#issuer}

يُطبع `issuer` أعلى المنتصف تحت الشعار. وإذا تركته استخدم القالب `company.name` من الهوية، فالشركة التي تصدر شهاداتها بنفسها تضبطه مرة واحدة في الإعدادات.

### التوقيعات {#signatures}

حتى ثلاثة توقيعات، لكل منها خط للتوقيع وتحته الاسم والصفة، موزعة بالتساوي على عرض الصفحة. والتوقيع الرابع يُرفض عند التحقق من البيانات، لأن الصفحة لا تتسع له.

### رمز التحقق QR {#qr}

يُطبع `verify_url` رمز QR في الركن العلوي، مع عبارة امسح الرمز للتحقق من الشهادة (Scan to verify). اجعله يشير إلى صفحة في تطبيقك تبحث عن الشهادة برقمها وتعرض اسم صاحبها والدورة. وإذا تركته لا يُطبع أي رمز.

## ملف Word {#word}

للشهادة ملف `pdf.html.php` لملف PDF، وملف `word.php` منفصل لملف Word، ويُبنى الاثنان من البيانات نفسها. ملف Word أيضاً A4 بالعرض، لكنه بلا إطار مزدوج: الشعار والجهة المانحة والعنوان والاسم والدورة والتفاصيل في وسط الصفحة بعضها تحت بعض، والتوقيعات متجاورة، ثم يأتي في أسفل المنتصف تاريخ الإصدار والرقم ورمز QR بدلاً من الأركان العلوية.

ملفات Word تحتاج إلى الحزمة `phpoffice/phpword`. انظر [ملفات Word](/ar/guide/word).

## تخصيص القالب {#customise}

```bash
php artisan doc:template certificate --as=my-certificate
```

ينسخ هذا الأمر القالب إلى `resources/doc-templates/my-certificate/`:

- `template.php`: الحقول، والقيم الافتراضية (مثل `'type' => 'attendance'`)، وإعدادات الصفحة؛
- `pdf.html.php`: تصميم PDF بالإطار وتنسيقات CSS (الألوان والمقاسات وشكل الإطار)؛
- `word.php`: تخطيط ملف Word؛
- `lang/ar.php` و`lang/en.php`: العناوين والصياغة لكل نوع وجنس.

عدّل `pdf.html.php` و`word.php` معاً حين تنقل العناصر، ليبقى الملفان متشابهين. واستخدم النسخة عبر `Doc::template('my-certificate', $data)`. انظر [قوالبك الخاصة](/ar/guide/custom-templates).
