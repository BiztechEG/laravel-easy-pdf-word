# عرض سعر

قالب `quotation` هو عرض السعر الذي ترسله الشركة إلى العميل قبل البيع: الأصناف بتفاصيلها ووحداتها، والخصومات، وضريبة اختيارية، والتفقيط، ومدة صلاحية العرض، والشروط، وتوقيع المرسل.

## متى تستخدمه {#when-to-use}

- شركة برمجيات ترسل لعميل مراحل مشروع، لكل مرحلة وصف قصير، مع خصم وشروط دفع.
- مورد يرد على طلب تسعير بأسعار الوحدات ومدة الصلاحية وشروط التوريد.
- فريق مبيعات يرسل عروضاً سريعة من نظام إدارة العملاء، بضريبة أو بدونها حسب العميل.
- مسودة عرض تذهب إلى المدير للمراجعة وعليها علامة مائية «مسودة» قبل إرسال النسخة النهائية.
- عميل يطلب العرض ملف Word ليضمه إلى أوراق الاعتماد لديه.

## مثال سريع {#example}

عرض السعر الذي في المعاينة أعلاه، وشركتك في رأسه، محفوظاً ملف PDF وملف Word:

```php
use BiztechEG\EasyPdfWord\Facades\Doc;

$quote = Doc::template('quotation', [
    'quote' => [
        'number' => 'QT-2026-0088',
        'date' => '2026-10-08',
        'valid_until' => '2026-11-07',
        'currency' => 'EGP',
        'tax_rate' => 14,
    ],
    'customer' => [
        'name' => 'مؤسسة النور للتجارة',
        'contact' => 'المهندس أحمد عبد الرحمن',
        'phone' => '+20 122 555 0100',
        'address' => 'مدينة نصر، القاهرة',
    ],
    'subject' => 'تنفيذ نظام إدارة المستندات الإلكترونية',
    'items' => [
        [
            'description' => 'تحليل المتطلبات وتصميم النظام',
            'details' => 'ورش عمل مع الأقسام وتوثيق كامل',
            'unit' => 'مرحلة',
            'quantity' => 1,
            'unit_price' => 18000,
        ],
        [
            'description' => 'تطوير النظام (Laravel)',
            'details' => 'الفواتير والخطابات والتقارير بالعربية والإنجليزية',
            'unit' => 'مرحلة',
            'quantity' => 1,
            'unit_price' => 42000,
            'discount' => 2000,
        ],
        ['description' => 'تدريب المستخدمين', 'unit' => 'يوم', 'quantity' => 3, 'unit_price' => 1500],
    ],
    'terms' => [
        'يسري هذا العرض لمدة 30 يوماً من تاريخه.',
        'الدفع: 40% عند التعاقد، و40% عند التسليم، و20% بعد شهر من التشغيل.',
        'مدة التنفيذ 45 يوم عمل من تاريخ استلام الدفعة الأولى.',
        'الدعم الفني مجاني لمدة 12 شهراً.',
    ],
    'sender' => ['name' => 'عمرو محمد', 'title' => 'المدير التنفيذي'],
])
    ->theme([
        // أو مرة واحدة للتطبيق كله، تحت "theme" في config/easy-pdf-word.php
        'company' => [
            'name' => 'شركة بيزتك للحلول البرمجية',
            'address' => '15 شارع التحرير، الدقي، الجيزة',
            'phone' => '+20 100 000 0000',
        ],
    ])
    ->locale('ar');

// ملف PDF
$quote->pdf()->save(storage_path('app/quotations/QT-2026-0088.pdf'));

// العرض نفسه ملف Word
$quote->word()->save(storage_path('app/quotations/QT-2026-0088.docx'));
```

يعرض العرض مجموعاً قدره 64,500.00 وخصماً قدره ‎-2,000.00 وصافياً قدره 62,500.00 وضريبة (14%) قدرها 8,750.00 وإجمالياً نهائياً قدره 71,250.00 ج.م، ثم «فقط واحد وسبعون ألفاً ومائتان وخمسون جنيهاً لا غير»، والشروط الأربعة مرقمة، ثم خانة التوقيع.

وفي الـ controller يرسل `return $quote->pdf()->download('QT-2026-0088.pdf');` الملف إلى المتصفح بدلاً من حفظه. انظر [الإخراج والتسليم](/ar/guide/output).

## الحقول {#fields}

| الحقل | إلزامي | النوع / القيم | القيمة الافتراضية | الوظيفة |
| --- | --- | --- | --- | --- |
| `quote.number` | نعم | نص أو رقم | | رقم العرض، أعلى الصفحة وفي تذييل الصفحة. |
| `quote.date` | نعم | تاريخ | | تاريخ العرض. |
| `quote.valid_until` | لا | تاريخ | | يُطبع بخط عريض «صالح حتى» / "Valid until" تحت التاريخ. |
| `quote.currency` | نعم | رمز من 3 أحرف | `EGP` | عملة كل المبالغ: الخانات العشرية والاختصار بعد الإجمالي والتفقيط. |
| `quote.tax_rate` | لا | رقم، صفر أو أكثر | `0` | نسبة ضريبة القيمة المضافة على الصافي بعد الخصم. عند الصفر لا يظهر سطر الضريبة. |
| `customer.name` | نعم | نص | | العميل، في خانة «السادة» / "To". |
| `customer.contact` | لا | نص | | الشخص الموجه إليه العرض، ويُطبع بعد «عناية» / "Attn.". |
| `customer.phone` | لا | نص | | هاتف العميل، ويُكتب من اليسار إلى اليمين. |
| `customer.address` | لا | نص | | عنوان العميل. |
| `subject` | لا | نص | | سطر الموضوع فوق الأصناف. |
| `items` | نعم | مصفوفة، عنصر واحد على الأقل | | الأصناف المعروضة، مرقمة 1، 2، 3. |
| `items.*.description` | نعم | نص | | اسم الصنف، ويُكتب بخط عريض إن كان له تفاصيل. |
| `items.*.details` | لا | نص | | سطر ثانٍ أصغر تحت الوصف. |
| `items.*.unit` | لا | نص | | الوحدة، مثل «يوم» أو «قطعة» أو «شهر». |
| `items.*.quantity` | نعم | رقم | | الكمية الصحيحة تُطبع بلا كسور، وغيرها بخانتين. |
| `items.*.unit_price` | نعم | رقم | | سعر الوحدة قبل الضريبة. |
| `items.*.discount` | لا | رقم، صفر أو أكثر | | مبلغ يُخصم من هذا السطر، ولا يزيد على الكمية × سعر الوحدة. |
| `terms` | لا | مصفوفة نصوص | `[]` | الشروط والأحكام، وتُطبع قائمة مرقمة تحت عنوان. |
| `notes` | لا | نص | | ملاحظات بعد الشروط. |
| `sender.name` | لا | نص | | الاسم في خانة التوقيع. |
| `sender.title` | لا | نص | | المسمى الوظيفي فوق الاسم. وبدون `sender` لا تظهر خانة التوقيع. |

الحقل الذي له قيمة افتراضية يُملأ قبل التحقق من البيانات، فيمكنك تركه حتى لو كان إلزامياً.

### القيم المحسوبة {#computed}

| القيمة | طريقة حسابها |
| --- | --- |
| `items.*.total` | الكمية × سعر الوحدة، مقربة لخانات العملة، ناقص خصم السطر |
| `totals.subtotal` | مجموع الكمية × سعر الوحدة |
| `totals.discount` | مجموع خصومات الأسطر |
| `totals.net` | المجموع ناقص الخصم |
| `totals.tax` | الصافي × `tax_rate` / 100، مقرباً |
| `totals.total` | الصافي مع الضريبة: الإجمالي النهائي |

ويتبع التفقيط لغة المستند: تفقيط عربي في العربية، وفي الإنجليزية يُكتب الرقم بالحروف عبر إضافة `intl` في PHP («seventy-one thousand two hundred fifty EGP only»). وبدون `intl` تحذف المستندات الإنجليزية هذا السطر.

### قيم الهوية {#theme}

| مفتاح الهوية | استخدامه |
| --- | --- |
| `company.name` و `company.address` و `company.phone` | المرسل أعلى الصفحة. وبدونها يكون الاسم قيمة `APP_NAME` في تطبيقك. |
| `logo` | فوق اسم الشركة |
| `primary` | اسم الشركة والعنوان ورأس الجدول وسطر الإجمالي |
| `muted` | العنوان البريدي والهاتف وكلمة «السادة» وتفاصيل الأصناف |
| `border` | خانة العميل |

## الأشكال والخيارات {#options}

### بضريبة أو بدونها {#vat}

القيمة الافتراضية لـ `quote.tax_rate` صفر، فلا ضريبة في العرض حتى تطلبها. اجعلها `'tax_rate' => 14` (مصر) أو `15` (السعودية) ليظهر سطر الضريبة. وتتكيف الأسطر تحت الأصناف مع البيانات:

- المجموع، دائماً؛
- الخصم والصافي بعد الخصم، عندما يكون في سطر ما خصم؛
- الضريبة، عندما تكون أكبر من صفر؛
- الإجمالي النهائي.

### الصلاحية والشروط والتوقيع {#validity}

يطبع `quote.valid_until` تاريخ صلاحية بخط عريض في رأس العرض. و `terms` قائمة جمل بسيطة، تُرقَّم 1، 2، 3 تحت «الشروط والأحكام» / "Terms and conditions". وينتهي العرض دائماً بـ «وتفضلوا بقبول فائق الاحترام،» / "Kind regards," تليها خانة `sender` (المسمى، ثم مساحة للتوقيع، ثم الاسم).

### مسودة بعلامة مائية {#draft}

عرض قصير بلا ضريبة ولا صلاحية ولا شروط، عليه علامة «مسودة»:

```php
$quote = Doc::template('quotation', [
    'quote' => ['number' => 'QT-2026-0091', 'date' => '2026-10-10'],
    'customer' => ['name' => 'مؤسسة النور للتجارة'],
    'items' => [
        ['description' => 'باقة استضافة سنوية', 'unit' => 'سنة', 'quantity' => 1, 'unit_price' => 5400],
    ],
])->locale('ar')->watermark('مسودة');
```

الإجمالي 5,400.00 ج.م («فقط خمسة آلاف وأربعمائة جنيه لا غير») وتمتد كلمة «مسودة» عبر الصفحة. العلامة المائية لملفات PDF فقط، ونسخة Word تخرج بدونها. انظر [إعدادات الصفحة](/ar/guide/page-settings).

## ملف Word {#word}

يبني `layout.php` ملف PDF وملف Word معاً، فلهما المحتوى نفسه بالترتيب نفسه. ويحتفظ تذييل الصفحة بالعنوان ورقم العرض و«صفحة X من Y» بحقول أرقام صفحات Word.

ملف Word بلا علامة مائية، ويرفض `->word()` أي مستند عليه `->password()`. ملفات Word تحتاج الحزمة `phpoffice/phpword`؛ انظر [ملفات Word](/ar/guide/word).

## خصّصه {#customise}

```bash
php artisan doc:template quotation --as=my-quotation
```

ينسخ هذا الأمر القالب إلى `resources/doc-templates/my-quotation`. استخدمه بـ `Doc::template('my-quotation', $data)` وعدّل:

- `lang/ar.php` و `lang/en.php` للعناوين: الجملة الافتتاحية تحت `intro`، والختام تحت `closing`، وأسماء الأعمدة.
- `template.php` للحقول والقيم الافتراضية، مثلاً `'quote' => ['currency' => 'SAR', 'tax_rate' => 15]` لإضافة الضريبة السعودية دائماً.
- `layout.php` لتخطيط الصيغتين.
- `footer.html.php` لتذييل الصفحة.

انظر [قوالبك الخاصة](/ar/guide/custom-templates).
