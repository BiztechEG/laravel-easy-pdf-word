# قسيمة راتب

قسيمة الراتب هي الكشف الشهري الذي يسلّمه قسم الرواتب أو شؤون العاملين لكل موظف: ما استحقه، وما استُقطع منه، وصافي راتبه. يطبع القالب `payslip` القسيمة على صفحة A4 واحدة، ويحسب لك الإجماليات وصافي الراتب بالأرقام وكتابةً.

## متى تستخدمه {#when-to-use}

- دورة الرواتب الشهرية: قسيمة لكل موظف، تُرسل إليه بالبريد أو تُجمع في ملف ZIP للمحاسب.
- بوابة الخدمة الذاتية للموظفين، حيث ينزّل الموظف قسيمة أي شهر سابق.
- صرف الرواتب نقداً أو بشيكات، حيث يوقّع كل موظف على القسيمة المطبوعة بالاستلام.
- شهر المكافآت أو التسوية النهائية، مع بنود استحقاق إضافية (مكافأة نهاية الخدمة، رصيد الإجازات).
- صورة من آخر القسائم لطلب قرض بنكي أو بطاقة ائتمان.

## مثال سريع {#example}

مرّر بيانات شهر واحد لموظف واحد إلى القالب:

```php
use BiztechEG\EasyPdfWord\Facades\Doc;

$payslip = Doc::template('payslip', [
    'period' => '2026-09',
    'number' => 'PS-2026-09-0142',
    'currency' => 'EGP',
    'employee' => [
        'name' => 'سارة محمود عبد الله',
        'code' => 'EMP-0142',
        'job_title' => 'مطورة برمجيات أولى',
        'department' => 'تقنية المعلومات',
        'national_id' => '29501011234567',
        'hire_date' => '2022-03-01',
        'bank' => 'البنك الأهلي المصري',
        'bank_account' => 'EG38 0003 0000 0000 1234 5678 901',
    ],
    'earnings' => [
        ['name' => 'الراتب الأساسي', 'amount' => 18000],
        ['name' => 'بدل سكن', 'amount' => 3000],
        ['name' => 'بدل انتقال', 'amount' => 1200],
        ['name' => 'ساعات إضافية', 'amount' => 1450],
    ],
    'deductions' => [
        ['name' => 'التأمينات الاجتماعية', 'amount' => 1980],
        ['name' => 'ضريبة كسب العمل', 'amount' => 2135.50],
        ['name' => 'قسط سلفة', 'amount' => 1000],
    ],
    'attendance' => [
        'working_days' => 22,
        'present_days' => 21,
        'leave_days' => 1,
        'overtime_hours' => 10,
    ],
    'payment' => ['method' => 'bank', 'date' => '2026-09-28'],
])->locale('ar');
```

ثم أعِد الملف الذي تحتاجه:

::: code-group

```php [PDF]
return $payslip->pdf()->download('PS-2026-09-0142.pdf');
```

```php [Word]
return $payslip->word()->download('PS-2026-09-0142.docx');
```

:::

النتيجة صفحة A4 واحدة، مثل المعاينة أعلاه:

- العنوان قسيمة راتب، والشهر مكتوباً باسمه: عن شهر سبتمبر 2026، ورقم القسيمة؛
- بيانات الموظف، كل حقلين في صف، والحساب البنكي في صف مستقل؛
- الاستحقاقات والاستقطاعات متجاورة، مع إجمالي الاستحقاقات 23,650.00 وإجمالي الاستقطاعات 5,115.50؛
- صافي الراتب في شريط `صافي الراتب 18,534.50 ج.م`، وتحته كتابةً: فقط ثمانية عشر ألفاً وخمسمائة وأربعة وثلاثون جنيهاً وخمسون قرشاً لا غير؛
- أربعة مربعات للحضور، وسطر طريقة الصرف: تحويل بنكي | تاريخ الصرف: 2026/09/28، وخانات التوقيع المحاسب، شؤون العاملين، توقيع الموظف بالاستلام؛
- تذييل الصفحة `سري - قسيمة راتب سبتمبر 2026 - EMP-0142` مع رقم الصفحة.

ومع `->locale('en')` يُكتب الشهر "For September 2026" والصافي "eighteen thousand five hundred thirty-four EGP and 50/100 only" (الكتابة بالإنجليزية تحتاج إلى إضافة PHP المسماة `intl`).

## الحقول {#fields}

يجري التحقق من البيانات قبل رسم أي شيء. ويمكن ترك الحقول التي لها قيمة افتراضية.

| الحقل | مطلوب | النوع أو القيم | القيمة الافتراضية | الوظيفة |
| --- | --- | --- | --- | --- |
| `period` | نعم | `YYYY-MM`، مثل `2026-09` | | الشهر، ويُطبع باسمه بلغة المستند: سبتمبر 2026، September 2026. |
| `number` | لا | نص | | رقم القسيمة، تحت العنوان. |
| `currency` | نعم | رمز من 3 أحرف | `EGP` | يحدد الخانات العشرية، واختصار العملة بجوار الصافي، واسم العملة في التفقيط. |
| `employee.name` | نعم | نص | | اسم الموظف، بخط عريض. |
| `employee.code` | لا | نص | | الرقم الوظيفي، ويظهر في التذييل أيضاً. |
| `employee.job_title` | لا | نص | | المسمى الوظيفي. |
| `employee.department` | لا | نص | | القسم. |
| `employee.national_id` | لا | نص | | الرقم القومي، من اليسار إلى اليمين. |
| `employee.hire_date` | لا | تاريخ | | تاريخ التعيين، بالشكل `2022/03/01`. |
| `employee.bank` | لا | نص | | اسم البنك، قبل رقم الحساب. |
| `employee.bank_account` | لا | نص | | رقم الحساب أو IBAN، في صف مستقل. |
| `earnings` | نعم | قائمة، بند واحد على الأقل | | بنود الاستحقاق: الراتب الأساسي، البدلات، الساعات الإضافية ... |
| `earnings.*.name` | نعم | نص | | اسم البند. |
| `earnings.*.amount` | نعم | رقم، 0 أو أكثر | | مبلغ البند. |
| `deductions` | لا | قائمة | فارغة | بنود الاستقطاع: التأمينات الاجتماعية، ضريبة الدخل، قسط سلفة ... |
| `deductions.*.name` | نعم | نص | | اسم البند. |
| `deductions.*.amount` | نعم | رقم، 0 أو أكثر | | مبلغ البند. |
| `attendance.working_days` | لا | رقم | | أيام العمل في الشهر. |
| `attendance.present_days` | لا | رقم | | أيام الحضور. |
| `attendance.absent_days` | لا | رقم | | أيام الغياب. |
| `attendance.leave_days` | لا | رقم | | أيام الإجازة. |
| `attendance.overtime_hours` | لا | رقم | | الساعات الإضافية. |
| `payment.method` | لا | `bank` أو `cash` أو `cheque` | | طريقة صرف الراتب: تحويل بنكي، نقداً، شيك. |
| `payment.date` | لا | تاريخ | | تاريخ الصرف. |
| `notes` | لا | نص | | سطر ملاحظات تحت سطر الصرف. |
| `signatures` | لا | قائمة نصوص | `accountant` و`hr` و`employee` | خانات التوقيع بالترتيب. انظر [التوقيعات](#signatures). |

يحسب القالب القيم التالية بنفسه، فلا تمررها:

| القيمة | طريقة حسابها |
| --- | --- |
| `totals.earnings` | مجموع `earnings.*.amount`، بعد تقريب كل مبلغ إلى خانات العملة. |
| `totals.deductions` | مجموع `deductions.*.amount`. |
| `totals.net` | `totals.earnings` ناقص `totals.deductions`، ويُطبع بالأرقام وكتابةً. |

### قيم الهوية {#theme}

| مفتاح الهوية | مكان ظهوره |
| --- | --- |
| `company.name` | الركن العلوي، بخط عريض وباللون الأساسي. |
| `company.address` | تحت اسم الشركة. |
| `logo` | فوق اسم الشركة، بعرض 30 مم. |
| `primary` | العنوان، وصف العناوين في جدول الاستحقاقات، وشريط صافي الراتب. |
| `muted` | عناوين الحقول، والتفقيط، وخطوط التوقيع. |
| `border` | خطوط جدول الموظف ومربعات الحضور. |

اضبطها في `config/easy-pdf-word.php` أو لكل مستند عبر `->theme([...])`؛ انظر [الإعدادات](/ar/guide/configuration).

## الأنواع والخيارات {#options}

### الاستحقاقات والاستقطاعات {#earnings-deductions}

تقع الاستحقاقات في جانب والاستقطاعات في الجانب الآخر، بند في كل صف؛ وإذا كانت إحدى القائمتين أطول بقي الجانب الآخر من تلك الصفوف فارغاً. ويحمل الصف الأخير الإجماليين. ويُقرَّب كل مبلغ إلى خانات العملة: خانتان لمعظم العملات، و3 خانات للعملات `KWD` و`BHD` و`OMR` و`JOD`. وإذا لم تكن هناك استقطاعات بقي جانبها فارغاً وكان الصافي مساوياً للاستحقاقات.

### الصافي كتابةً {#net-in-words}

يُكتب صافي الراتب بالحروف بلغة المستند، تحت شريط الصافي:

- في المستندات العربية بالتفقيط مع اسم العملة: جنيهاً وقرشاً للعملة `EGP`، وريال وهللة للعملة `SAR`، ودينار وفلس للعملة `KWD`، وهكذا؛
- في المستندات الإنجليزية عبر الإضافة `intl`: "eighteen thousand five hundred thirty-four EGP and 50/100 only". ومن دون `intl` يُحذف هذا السطر.

وإذا زادت الاستقطاعات على الاستحقاقات صار الصافي سالباً، ويُحذف سطر التفقيط.

لقسيمة راتب سعودية، اضبط العملة والتوقيعات التي تستخدمها:

```php
$data['currency'] = 'SAR';
$data['signatures'] = ['hr', 'المدير العام'];
```

يظهر الصافي حينئذ بالاختصار `ر.س` ويُكتب بالريال، وتظهر خانتا التوقيع شؤون العاملين والمدير العام.

### الشهر {#period}

يأخذ الحقل `period` الشهر بالشكل `2026-09`، ويطبعه القالب باسمه بلغة المستند: عن شهر سبتمبر 2026 بالعربية، وFor September 2026 بالإنجليزية. ويظهر اسم الشهر نفسه في التذييل.

### بيانات الموظف {#employee}

يعرض جدول الموظف كل حقلين في صف، ويتخطى ما لم تمرره. ويبقى الرقم الوظيفي والرقم القومي من اليسار إلى اليمين داخل النص العربي. ويشترك `bank` و`bank_account` في صف مستقل بعنوان الحساب البنكي، ليتسع لرقم IBAN الطويل.

### الحضور {#attendance}

يرسم القالب مربعاً لكل رقم حضور تمرره، بالترتيب الذي تمرره به، ولا يرسم الصف إذا لم يوجد `attendance`. والقيم العشرية، مثل `1.5` يوم إجازة، تُطبع كما هي.

### الصرف والملاحظات {#payment}

يطبع `payment.method` و`payment.date` سطراً واحداً: طريقة الصرف: تحويل بنكي | تاريخ الصرف: 2026/09/28، ويمكن ترك أي جزء منهما. ويضيف `notes` سطراً تحته.

| `payment.method` | بالعربية | بالإنجليزية |
| --- | --- | --- |
| `bank` | تحويل بنكي | Bank transfer |
| `cash` | نقداً | Cash |
| `cheque` | شيك | Cheque |

### التوقيعات {#signatures}

يحدد `signatures` خانات التوقيع بالترتيب. الأدوار التالية تُترجم، وأي نص آخر يُطبع كما كتبته:

| الدور | بالعربية | بالإنجليزية |
| --- | --- | --- |
| `accountant` | المحاسب | Accountant |
| `hr` | شؤون العاملين | Human resources |
| `employee` | توقيع الموظف بالاستلام | Received by employee |

مرّر قائمة فارغة `'signatures' => []` لتختفي خانات التوقيع، مثلاً في القسائم التي تُرسل بالبريد فقط.

### تذييل الصفحة {#footer}

في كل صفحة تذييل صغير: `سري - قسيمة راتب سبتمبر 2026 - EMP-0142` في جانب، ورقم الصفحة في الجانب الآخر. ولا يُضاف الرقم الوظيفي إلا إذا مررت `employee.code`.

## ملف Word {#word}

للقسيمة ملف `layout.php` واحد يبني الملفين معاً، لذلك يحمل ملف Word الجداول نفسها، وشريط الصافي، ومربعات الحضور، وخانات التوقيع كما في PDF. ويصبح التذييل سطراً من نص رمادي صغير في تذييل Word، مع أرقام صفحات Word. ويمكن لشؤون العاملين فتح ملف Word لإضافة ملاحظة قبل إرساله.

ملفات Word تحتاج إلى الحزمة `phpoffice/phpword`. انظر [ملفات Word](/ar/guide/word).

## تخصيص القالب {#customise}

```bash
php artisan doc:template payslip --as=my-payslip
```

ينسخ هذا الأمر القالب إلى `resources/doc-templates/my-payslip/`:

- `template.php`: الحقول والقيم الافتراضية، مثل `'currency' => 'SAR'`؛
- `layout.php`: تخطيط ملف PDF وملف Word معاً؛
- `footer.blade.php`: التذييل السري؛
- `lang/ar.php` و`lang/en.php`: العناوين. ففي السعودية مثلاً قد تغيّر `'national_id' => 'الرقم القومي'` إلى `'رقم الهوية / الإقامة'`.

استخدم النسخة عبر `Doc::template('my-payslip', $data)`. وأي حقل جديد يحتاج إلى قاعدة في `template.php` وسطر في `layout.php` يطبعه. انظر [قوالبك الخاصة](/ar/guide/custom-templates).
