# إشعار دائن ومدين

قالب `credit-note` هو الإشعار الذي يصدره البائع لتصحيح فاتورة أرسلها من قبل: الإشعار الدائن يُنقص ما على العميل، والإشعار المدين يزيده. يذكر الفاتورة الأصلية وسبب الإصدار، ويعرض الأصناف والمبالغ، ويضيف الضريبة والتفقيط، ويمكن أن يحمل رمز QR لهيئة الزكاة أو لأي رابط.

## متى تستخدمه {#when-to-use}

- يرد العميل جزءاً من طلبه، فتُصدر إشعاراً دائناً بالأصناف المرتجعة وضريبتها.
- يُلغى اشتراك في منتصف السنة، فتُضيف إلى رصيد العميل الأشهر التي لم يستخدمها.
- يوم تدريب أو خدمة في الفاتورة لم تُنفذ.
- فرق سعر أو كمية زائدة احتُسبت بأقل من قيمتها، فتُصدر إشعاراً مديناً بالفرق.
- بائع في السعودية يصحح فاتورة ضريبية مبسطة ويطبع الإشعار برمز QR لهيئة الزكاة.

## مثال سريع {#example}

الإشعار الدائن الذي في المعاينة أعلاه، محفوظاً ملف PDF وملف Word:

```php
use BiztechEG\EasyPdfWord\Facades\Doc;

$note = Doc::template('credit-note', [
    'type' => 'credit',
    'note' => [
        'number' => 'CN-2026-0057',
        'date' => '2026-10-08',
        'currency' => 'EGP',
        'tax_rate' => 14,
    ],
    'invoice' => [
        'number' => 'INV-2026-1024',
        'date' => '2026-09-20',
    ],
    'reason' => 'إلغاء ثلاثة أشهر من اشتراك الاستضافة ويوم تدريب لم يُنفذ',
    'seller' => [
        'name' => 'شركة بيزتك للحلول البرمجية',
        'address' => '15 شارع التحرير، الدقي، الجيزة',
        'tax_number' => '123-456-789',
    ],
    'buyer' => [
        'name' => 'مؤسسة النور للتجارة',
        'address' => 'مدينة نصر، القاهرة',
        'tax_number' => '987-654-321',
    ],
    'items' => [
        ['description' => 'استضافة سحابية - اشتراك شهري', 'quantity' => 3, 'unit_price' => 450],
        ['description' => 'تدريب فريق العمل', 'quantity' => 1, 'unit_price' => 1500],
    ],
    'qr' => 'https://example.com/credit-notes/CN-2026-0057',
    'notes' => 'سيتم خصم قيمة الإشعار من الدفعة القادمة.',
])->locale('ar');

// ملف PDF
$note->pdf()->save(storage_path('app/credit-notes/CN-2026-0057.pdf'));

// الإشعار نفسه ملف Word
$note->word()->save(storage_path('app/credit-notes/CN-2026-0057.docx'));
```

يعرض الإشعار مجموعاً فرعياً قدره 2,850.00 وضريبة (14%) قدرها 399.00 وإجمالياً قدره 3,249.00 ج.م، ثم «فقط ثلاثة آلاف ومائتان وتسعة وأربعون جنيهاً لا غير» وجملة «أُضيفت قيمة هذا الإشعار إلى رصيد حسابكم لدينا.».

وفي الـ controller يرسل `return $note->pdf()->download('CN-2026-0057.pdf');` الملف إلى المتصفح بدلاً من حفظه. انظر [الإخراج والتسليم](/ar/guide/output).

## الحقول {#fields}

| الحقل | إلزامي | النوع / القيم | القيمة الافتراضية | الوظيفة |
| --- | --- | --- | --- | --- |
| `type` | نعم | `credit` أو `debit` | `credit` | يحدد العنوان وتذييل الصفحة والجملة الختامية. |
| `note.number` | نعم | نص أو رقم | | رقم الإشعار، أعلى الصفحة وفي التذييل. |
| `note.date` | نعم | تاريخ | | تاريخ إصدار الإشعار، وهو أيضاً الوقت في رمز هيئة الزكاة. |
| `note.currency` | نعم | رمز من 3 أحرف | `EGP` | عملة كل المبالغ: الخانات العشرية والاختصار بعد الإجمالي والتفقيط. |
| `note.tax_rate` | لا | رقم، صفر أو أكثر | `14` | نسبة ضريبة القيمة المضافة على المجموع بعد الخصم. عند الصفر يُحذف سطر الضريبة. |
| `invoice.number` | نعم | نص أو رقم | | الفاتورة الأصلية، في خانة «الفاتورة الأصلية». |
| `invoice.date` | لا | تاريخ | | تاريخ الفاتورة الأصلية. |
| `reason` | نعم | نص | | سبب إصدار الإشعار، ويُطبع فوق الأصناف. |
| `seller` | لا | مصفوفة | `company` في الهوية | البائع. كل مفتاح تمرره يحل محل المفتاح نفسه في بيانات الشركة في الهوية. المفاتيح المقروءة: `name` و `address` و `tax_number`. |
| `buyer.name` | نعم | نص | | العميل. |
| `buyer.address` | لا | نص | | عنوان العميل. |
| `buyer.tax_number` | لا | نص | | الرقم الضريبي للعميل. |
| `items` | نعم | مصفوفة، عنصر واحد على الأقل | | الأسطر المردودة أو المضافة، مرقمة 1، 2، 3. |
| `items.*.description` | نعم | نص | | ما يُرد أو يُضاف. |
| `items.*.quantity` | نعم | رقم، صفر أو أكثر | | الكمية. |
| `items.*.unit_price` | نعم | رقم، صفر أو أكثر | | سعر الوحدة قبل الضريبة. |
| `items.*.discount` | لا | رقم، صفر أو أكثر | | مبلغ يُخصم من هذا السطر، ولا يزيد على الكمية × سعر الوحدة. |
| `qr` | لا | نص | `null` | القيمة `'zatca'` تبني رمز QR لهيئة الزكاة من الإشعار؛ وأي نص آخر يوضع في الرمز كما هو؛ و `null` بلا رمز. |
| `notes` | لا | نص | | ملاحظات في آخر الإشعار. |

الحقل الذي له قيمة افتراضية يُملأ قبل التحقق من البيانات، فيمكنك تركه حتى لو كان إلزامياً. ولا تُقبل الكميات والأسعار السالبة: الحقل `type` هو الذي يحدد اتجاه المبلغ.

### القيم المحسوبة {#computed}

| القيمة | طريقة حسابها |
| --- | --- |
| `items.*.total` | الكمية × سعر الوحدة، مقربة لخانات العملة، ناقص خصم السطر |
| `totals.subtotal` | مجموع الكمية × سعر الوحدة |
| `totals.discount` | مجموع خصومات الأسطر |
| `totals.taxable` | المجموع الفرعي ناقص الخصم («الصافي بعد الخصم»، ويُطبع عند وجود خصم) |
| `totals.tax` | الخاضع للضريبة × `tax_rate` / 100، مقرباً |
| `totals.total` | الخاضع للضريبة مع الضريبة: «إجمالي الإشعار» |
| `seller` | بيانات الشركة في الهوية مدموجة مع `seller` الذي مررته |
| `qr` | مع `'zatca'` تُستبدل بمحتوى رمز هيئة الزكاة بترميز base64 |

وتحت الإجمالي يطبع القالب التفقيط بلغة المستند: تفقيط عربي في العربية، وفي الإنجليزية يُكتب الرقم بالحروف عبر إضافة `intl` في PHP («three thousand two hundred forty-nine EGP only»). وبدون `intl` تحذف المستندات الإنجليزية هذا السطر.

### قيم الهوية {#theme}

| مفتاح الهوية | استخدامه |
| --- | --- |
| `company.name` و `company.address` و `company.tax_number` | بيانات البائع الافتراضية |
| `logo` | فوق اسم البائع أعلى الصفحة |
| `primary` | اسم البائع والعنوان ورأس الجدول وسطر الإجمالي |
| `muted` | العنوان البريدي والعناوين الصغيرة والتفقيط ونص رمز QR |
| `border` | خانتا العميل والفاتورة الأصلية |

## الأشكال والخيارات {#options}

### دائن أو مدين {#credit-or-debit}

| `type` | العنوان العربي | العنوان الإنجليزي | الجملة الختامية |
| --- | --- | --- | --- |
| `credit` | إشعار دائن | Credit Note | أُضيفت قيمة هذا الإشعار إلى رصيد حسابكم لدينا. / This amount has been credited to your account with us. |
| `debit` | إشعار مدين | Debit Note | قُيدت قيمة هذا الإشعار على حسابكم لدينا. / This amount has been debited to your account with us. |

### رمز هيئة الزكاة {#zatca}

إشعار مدين سعودي عن فرق سعر، برمز QR لهيئة الزكاة مبني من الإشعار:

```php
$note = Doc::template('credit-note', [
    'type' => 'debit',
    'note' => [
        'number' => 'DN-2026-0012',
        'date' => '2026-10-08',
        'currency' => 'SAR',
        'tax_rate' => 15,
    ],
    'invoice' => ['number' => 'SA-2026-0451', 'date' => '2026-10-01'],
    'reason' => 'فرق سعر على الكمية الموردة بعد تعديل عقد التوريد',
    'seller' => [
        'name' => 'مؤسسة النور للتجارة',
        'tax_number' => '300000000000003',
    ],
    'buyer' => ['name' => 'شركة الأفق للمقاولات'],
    'items' => [
        ['description' => 'فرق سعر - 50 كرتونة ورق A4', 'quantity' => 50, 'unit_price' => 12],
    ],
    'qr' => 'zatca',
])->locale('ar');
```

الإجمالي 690.00 ر.س (600.00 مع ضريبة 90.00). ويحمل الرمز اسم البائع ورقمه الضريبي، وتاريخ الإشعار بتوقيت UTC (`2026-10-08T00:00:00Z` للتاريخ الذي بلا وقت)، و `690.00` و `90.00`. وأي نص آخر في `qr`، مثل رابط الإشعار في تطبيقك، يوضع في الرمز كما هو، وتحته «امسح الرمز للتحقق من الإشعار».

### أعمدة وأسطر تظهر عند الحاجة {#optional-rows}

- يظهر عمود الخصم فقط عندما يكون في سطر ما خصم؛ ومع الخصم تعرض الإجماليات أيضاً الخصم والصافي بعد الخصم.
- يظهر سطر الضريبة فقط عندما تكون الضريبة أكبر من صفر، فالإشعار الذي فيه `'tax_rate' => 0` ينتقل من المجموع الفرعي إلى الإجمالي مباشرة.

### الفاتورة الإلكترونية المصرية {#eta}

للإشعار الدائن أو المدين الذي يُرسل إلى مصلحة الضرائب المصرية، استخدم قالب [الفاتورة الإلكترونية المصرية](/ar/templates/eg-invoice) مع `'type' => 'C'` أو `'D'`: فهو يطبع حقول المنظومة وأكواد الأصناف وأنواع الضرائب.

## ملف Word {#word}

يبني `layout.php` ملف PDF وملف Word معاً، فلهما المحتوى نفسه بالترتيب نفسه. ويحتفظ تذييل الصفحة بالعنوان ورقم الإشعار و«صفحة X من Y» بحقول أرقام صفحات Word.

ملف Word بلا علامة مائية، ويرفض `->word()` أي مستند عليه `->password()`. ملفات Word تحتاج الحزمة `phpoffice/phpword`؛ انظر [ملفات Word](/ar/guide/word).

## خصّصه {#customise}

```bash
php artisan doc:template credit-note --as=my-credit-note
```

ينسخ هذا الأمر القالب إلى `resources/doc-templates/my-credit-note`. استخدمه بـ `Doc::template('my-credit-note', $data)` وعدّل:

- `lang/ar.php` و `lang/en.php` للعناوين: أسماء الإشعار تحت `title`، والجمل الختامية تحت `effect`، ونص رمز QR تحت `verify`.
- `template.php` للحقول والقيم الافتراضية (العملة ونسبة الضريبة) والإجماليات في `prepare()`.
- `layout.php` لتخطيط الصيغتين.
- `footer.blade.php` لتذييل الصفحة.

انظر [قوالبك الخاصة](/ar/guide/custom-templates).
