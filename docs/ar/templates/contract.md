# عقد

عقد بين طرفين أو أكثر، مثل عقود الخدمات أو التوريد أو الإيجار أو العمل التي يعدّها فريق الشؤون القانونية أو المبيعات أو الموارد البشرية. يرقّم القالب `contract` البنود بالكلمات العربية (البند الأول، البند الثاني ...)، ويضيف خانة توقيع لكل طرف، والشهود، والتوقيع المختصر في كل صفحة.

## متى تستخدمه {#when-to-use}

- يقبل العميل عرض السعر، فترسل إليه عقد خدمات أو تطوير برمجيات للتوقيع.
- عقود توريد أو صيانة بالبنود نفسها لعملاء كثيرين، تُملأ من قاعدة بياناتك.
- عقود إيجار مكتب أو محل أو معدات، وفي بنودها القيمة الإيجارية والمدة والتأمين.
- عقود العمل التي تُنشأ من ملف كل موظف جديد في الموارد البشرية.
- اتفاقات مع طرف ثالث، مثل بنك ضامن أو مقاول من الباطن.

النتيجة عقد من صفحتين A4:

- العنوان و`رقم العقد: C-2026-031`، ثم عبارة الافتتاح، واسم اليوم مستخرج من التاريخ: إنه في يوم الخميس الموافق 2026/10/08 تحرر هذا العقد في القاهرة بين كل من:
- جدول بالأطراف: الطرف الأول (مقدم الخدمة) والطرف الثاني (العميل)، ولكل منهما رقم السجل والعنوان والممثل القانوني: عمرو محمد (المدير التنفيذي)؛
- التمهيد تحت عنوان تمهيد، ثم عبارة: وبعد أن أقر الطرفان بأهليتهما القانونية للتعاقد، اتفقا على ما يلي:
- البنود من البند الأول: التمهيد إلى البند السادس: فض النزاعات، وكل سطر من نص البند فقرة مستقلة؛
- عبارة الختام: حُرر هذا العقد من نسختين، بيد كل طرف نسخة للعمل بموجبها عند اللزوم.
- خانة توقيع لكل طرف، وخانة لكل شاهد (الشاهد الأول، الشاهد الثاني)؛
- في كل صفحة تذييل فيه خانات التوقيع المختصر (توقيع الطرف الأول: ....) وعنوان العقد ورقمه ورقم الصفحة.

## الحقول {#fields}

يجري التحقق من البيانات قبل رسم أي شيء. ويمكن ترك الحقول التي لها قيمة افتراضية.

| الحقل | مطلوب | النوع أو القيم | القيمة الافتراضية | الوظيفة |
| --- | --- | --- | --- | --- |
| `contract.title` | نعم | نص | | عنوان العقد في الأعلى، ويظهر في التذييل أيضاً. |
| `contract.number` | لا | نص | | رقم العقد، تحت العنوان وفي التذييل. |
| `contract.date` | نعم | تاريخ | | التاريخ في عبارة الافتتاح، مع اسم اليوم (الخميس / Thursday). |
| `contract.place` | لا | نص | | مكان تحرير العقد. وبدونه تخلو عبارة الافتتاح من المكان. |
| `parties` | نعم | قائمة، طرفان على الأقل | | الأطراف بالترتيب: الأول هو الطرف الأول، والثاني الطرف الثاني ... |
| `parties.*.name` | نعم | نص | | اسم الطرف، بخط عريض. |
| `parties.*.alias` | لا | نص | | الصفة التي يذكرها العقد للطرف، مثل مقدم الخدمة أو المؤجر، وتُطبع بين قوسين. |
| `parties.*.id_label` | لا | نص | | العبارة قبل `id`، مثل سجل تجاري رقم أو رقم قومي. |
| `parties.*.id` | لا | نص | | رقم السجل أو الهوية، من اليسار إلى اليمين. |
| `parties.*.address` | لا | نص | | عنوان الطرف. |
| `parties.*.represented_by` | لا | نص | | من يوقّع عن الطرف (الممثل القانوني). |
| `parties.*.capacity` | لا | نص | | صفة الموقّع، وتُطبع بين قوسين بعد اسمه. |
| `preamble` | لا | نص | | التمهيد. كل سطر فيه فقرة. |
| `clauses` | نعم | قائمة، بند واحد على الأقل | | البنود، مرقّمة بترتيبها. |
| `clauses.*.title` | لا | نص | | عنوان البند بعد رقمه: البند الأول: موضوع العقد. |
| `clauses.*.text` | نعم | نص | | نص البند. كل سطر فيه فقرة. |
| `copies` | لا | عدد صحيح، 1 أو أكثر | `2` | عدد النسخ في عبارة الختام. |
| `closing` | لا | نص | | يحل محل عبارة الختام الخاصة بالنسخ. |
| `witnesses` | لا | قائمة أسماء | فارغة | خانة توقيع لكل شاهد. |

### قيم الهوية {#theme}

| مفتاح الهوية | مكان ظهوره |
| --- | --- |
| `logo` | في المنتصف فوق العنوان، بعرض 30 مم. |
| `primary` | العنوان، والخط تحته، وعناوين البنود، وتسميات الأطراف. |
| `muted` | رقم العقد، وصفات الأطراف، وخطوط التوقيع. |
| `border` | خطوط جدول الأطراف. |

لا يطبع العقد اسم الشركة من الهوية: كل الأطراف، ومنها شركتك، تأتي من `parties`.

## الأنواع والخيارات {#options}

### الأطراف {#parties}

لكل طرف صف في جدول الأطراف وخانة توقيع في النهاية. وتأتي تسميته من ترتيبه، بالكلمات حتى الطرف العشرين (الطرف الأول، الطرف الثاني ... الطرف العشرون بالعربية، وFirst party ... Twentieth party بالإنجليزية)، ويضيف `alias` الصفة التي تستخدمها البنود، مثل (العميل). ويطبع `id_label` و`id` سطراً واحداً، مثل سجل تجاري رقم 123456 أو رقم قومي 29501011234567؛ ومرّر `id` وحده لطباعة الرقم فقط.

### ثلاثة أطراف أو أكثر {#more-parties}

أضف مصفوفة ثالثة إلى `parties`، مثل طرف ضامن:

```php
$data['parties'][] = [
    'name' => 'بنك القاهرة',
    'alias' => 'الضامن',
    'id_label' => 'سجل تجاري رقم',
    'id' => '778899',
];
```

مع ثلاثة أطراف أو أكثر يغيّر القالب عبارة الاتفاق إلى الجمع: وبعد أن أقرت الأطراف بأهليتها القانونية للتعاقد، اتفقت على ما يلي، ويطبع خانات التوقيع ثلاثاً في كل صف، ويضيف خانة توقيع مختصر للطرف الثالث في التذييل. ويتسع التذييل لتوقيعات أول ثلاثة أطراف.

### ترقيم البنود {#clauses}

تُرقّم البنود بترتيبها في القائمة، أياً كانت مفاتيح المصفوفة:

- بالعربية، بكلمات الترتيب من البند الأول إلى البند العشرون، ومن البند الحادي والعشرين فصاعداً بالأرقام: البند 21؛
- بالإنجليزية، بالأرقام: Clause 1، Clause 2.

كل سطر في `text` يصبح فقرة مستقلة، لذا تُكتب القوائم بفواصل أسطر (`\n`) وبأرقامك أنت، كما في بند موضوع العقد أعلاه. والبند الذي ليس له `title` يظهر برقمه فقط.

### النسخ وعبارة الختام {#copies}

تذكر عبارة الختام عدد النسخ بالكلمات: نسخة واحدة، نسختين، ثلاث نسخ ... حتى عشر نسخ بالعربية، وحتى five copies بالإنجليزية؛ وبعد ذلك بالأرقام، مثل حُرر هذا العقد من 12 نسخة. ولكتابة عبارتك الخاصة مرّر `closing`:

```php
$data['closing'] = 'حُرر هذا العقد من ثلاث نسخ أصلية، تسلم كل طرف نسخة منها، وأودعت الثالثة لدى الضامن.';
```

### الشهود {#witnesses}

الحقل `witnesses` قائمة أسماء. لكل شاهد خانة فيها تسميته (الشاهد الأول، الشاهد الثاني ... / Witness 1، Witness 2 ...)، والاسم، وخط للتوقيع، ثلاث خانات في كل صف تحت عنوان الشهود.

### التوقيع المختصر في كل صفحة {#initials}

يتكرر التذييل في كل صفحة: خانة لكل طرف من أول ثلاثة أطراف ليوقّع على الصفحة (توقيع الطرف الأول: ....... / First party initials)، ثم عنوان العقد ورقمه، ثم صفحة 1 من 2. ولهذا السبب الهامش السفلي للقالب أكبر (28 مم).

## ملف Word {#word}

للعقد ملف `layout.php` واحد يبني الملفين معاً، لذلك يحمل ملف Word العناوين نفسها، وجدول الأطراف، والبنود، وخانات التوقيع، والشهود كما في PDF. ويصبح التذييل سطراً واحداً من نص رمادي صغير في تذييل Word: التوقيعات المختصرة، والعنوان والرقم، وأرقام صفحات Word.

ملفات Word تحتاج إلى الحزمة `phpoffice/phpword`. انظر [ملفات Word](/ar/guide/word).

## تخصيص القالب {#customise}

```bash
php artisan doc:template contract --as=my-contract
```

ينسخ هذا الأمر القالب إلى `resources/doc-templates/my-contract/`:

- `template.php`: الحقول والقيم الافتراضية، مثل `'copies' => 3`؛
- `layout.php`: تخطيط ملف PDF وملف Word معاً؛
- `footer.blade.php`: تذييل التوقيعات المختصرة وأرقام الصفحات؛
- `lang/ar.php` و`lang/en.php`: عبارتا الافتتاح والختام، وكلمات الترتيب، وكل العناوين. ففي عقد الإيجار مثلاً قد تغيّر `intro` لتبدأ بصيغتك الخاصة.

استخدم النسخة عبر `Doc::template('my-contract', $data)`. انظر [قوالبك الخاصة](/ar/guide/custom-templates).
