# الفاتورة الإلكترونية المصرية

قالب `eg-invoice` يطبع الفاتورة الإلكترونية أو الإشعار الدائن أو المدين الذي يرسله البائع المصري إلى منظومة الفاتورة الإلكترونية في مصلحة الضرائب المصرية. حقوله تتبع مستند المنظومة، فتطبع البيانات نفسها التي ترسلها: أرقام التسجيل الضريبي وأكواد الأصناف وأنواع الضرائب، مع رمز QR يفتح المستند على بوابة المصلحة.

القالب يطبع المستند فقط. توقيعه وإرساله إلى واجهة المنظومة (API) من مهام تطبيقك أو مزود خدمة الفاتورة الإلكترونية لديك؛ وبعد قبوله، يعطي الرقم الإلكتروني (UUID) والمعرّف الطويل (long ID) اللذان تعيدهما المنظومة رمز QR.

## متى تستخدمه {#when-to-use}

- بعد قبول الفاتورة في المنظومة، ترسل للعميل نسخة PDF برقمها الإلكتروني ورمز QR يفتحها على البوابة.
- تُصدر إشعاراً دائناً (النوع `C`) لبضاعة مرتجعة، أو إشعاراً مديناً (النوع `D`) لزيادة سعر، على فواتير أُرسلت من قبل.
- تبيع سلعاً عليها ضريبة جدول (T2 و T3) أو رسوم، وتعرض كل ضريبة في سطرها وفي ملخص الضرائب.
- تُصدر فاتورة خدمات يُخصم منها الخصم تحت حساب الضريبة (T4).
- تبيع لشخص برقمه القومي أو لمشترٍ أجنبي برقم جواز سفره، لا للشركات فقط.

## مثال سريع {#example}

بيانات المعاينة أعلاه، محفوظة ملف PDF وملف Word:

```php
use BiztechEG\EasyPdfWord\Facades\Doc;

$einvoice = Doc::template('eg-invoice', [
    'document' => [
        'type' => 'I',
        'internal_id' => 'INV-2026-1024',
        'issued_at' => '2026-10-08 11:45',
        'uuid' => 'R6ZQ4SB1ZWP2XKCV2G0AYXHG10',
        'long_id' => 'A3MZ7X0NE6C8XH3GV2G0AYXHG10QN3K91653372781',
        'currency' => 'EGP',
        'purchase_order' => 'PO-7781',
    ],
    'issuer' => [
        'name' => 'شركة بيزتك للحلول البرمجية',
        'rin' => '123456789',
        'branch_id' => '0',
        'activity_code' => '6201',
        'address' => '15 شارع التحرير، الدقي، الجيزة',
    ],
    'receiver' => [
        'type' => 'B',
        'id' => '987654321',
        'name' => 'مؤسسة النور للتجارة',
        'address' => 'مدينة نصر، القاهرة',
    ],
    'lines' => [
        [
            'description' => 'تطوير نظام إدارة المخزون',
            'item_type' => 'EGS',
            'item_code' => 'EG-123456789-1001',
            'unit' => 'EA',
            'quantity' => 1,
            'unit_price' => 25000,
            'taxes' => [
                ['type' => 'T1', 'rate' => 14],
                ['type' => 'T4', 'subtype' => 'W010', 'rate' => 3],
            ],
        ],
        [
            'description' => 'استضافة سحابية - اشتراك شهري',
            'item_type' => 'EGS',
            'item_code' => 'EG-123456789-2002',
            'unit' => 'MON',
            'quantity' => 12,
            'unit_price' => 450,
            'discount' => 400,
            'taxes' => [
                ['type' => 'T1', 'rate' => 14],
            ],
        ],
    ],
])->locale('ar');

// ملف PDF
$einvoice->pdf()->save(storage_path('app/e-invoices/INV-2026-1024.pdf'));

// المستند نفسه ملف Word
$einvoice->word()->save(storage_path('app/e-invoices/INV-2026-1024.docx'));
```

إجمالي السطر الأول 27,750.00 (25,000 مع ضريبة 3,500 ناقص خصم تحت حساب الضريبة 750)، والثاني 5,700.00 (5,000 مع ضريبة 700). ويعرض الملخص: إجمالي المبيعات 30,400.00، وإجمالي الخصومات ‎-400.00، وصافي المبيعات 30,000.00، و T1 بقيمة 4,200.00، و T4 بقيمة ‎-750.00، وإجمالي الفاتورة 33,450.00 ج.م، مع «فقط ثلاثة وثلاثون ألفاً وأربعمائة وخمسون جنيهاً لا غير» ورمز QR للبوابة.

وفي الـ controller يرسل `return $einvoice->pdf()->download('INV-2026-1024.pdf');` الملف إلى المتصفح بدلاً من حفظه. انظر [الإخراج والتسليم](/ar/guide/output).

## الحقول {#fields}

| الحقل | إلزامي | النوع / القيم | القيمة الافتراضية | الوظيفة |
| --- | --- | --- | --- | --- |
| `document.type` | نعم | `I` أو `C` أو `D` | `I` | فاتورة أو إشعار دائن أو إشعار مدين: يحدد العنوان وتذييل الصفحة. |
| `document.internal_id` | نعم | نص أو رقم | | الرقم الداخلي للمستند عندك، أعلى الصفحة وفي التذييل. |
| `document.issued_at` | نعم | تاريخ ووقت | | وقت الإصدار، ويُطبع بالشكل `2026/10/08 11:45` بالمنطقة الزمنية للتطبيق. ويُحوَّل وقت المنظومة المكتوب بتوقيت UTC (`2026-10-08T09:45:00Z`). |
| `document.uuid` | لا | نص | | الرقم الإلكتروني الذي أعادته المنظومة، ويُطبع تحت رأس المستند. ومع `long_id` يبني رمز QR للبوابة. |
| `document.long_id` | لا | نص | | المعرّف الطويل الذي أعادته المنظومة، ولا يُستخدم إلا في رابط رمز QR. |
| `document.submission_uuid` | لا | نص | | رقم الإرسال الذي أعادته المنظومة، ويُطبع تحت الرقم الإلكتروني بعنوان «رقم الإرسال» (Submission ID). |
| `document.purchase_order` | لا | نص | | رقم أمر الشراء، ويُطبع تحت وقت الإصدار. |
| `document.currency` | نعم | رمز من 3 أحرف | `EGP` | عملة كل المبالغ: الخانات العشرية والاختصار بعد الإجمالي والتفقيط. |
| `issuer.name` | نعم | نص | | اسم البائع المسجل، أعلى الصفحة وفي خانة «بيانات البائع». |
| `issuer.rin` | نعم | نص | | رقم التسجيل الضريبي للبائع. |
| `issuer.branch_id` | لا | نص أو رقم | | كود الفرع؛ والقيمة `'0'` (الفرع الرئيسي) تُطبع أيضاً. |
| `issuer.activity_code` | لا | نص | | كود النشاط في المنظومة، مثل `6201`. |
| `issuer.address` | لا | نص | | عنوان البائع، أعلى الصفحة وفي خانته. |
| `receiver.type` | نعم | `B` أو `P` أو `F` | `B` | شركة أو شخص أو أجنبي: يحدد عنوان `receiver.id`. |
| `receiver.id` | لا | نص | | رقم التسجيل الضريبي أو الرقم القومي أو رقم جواز السفر، حسب النوع. |
| `receiver.name` | نعم | نص | | اسم المشتري. |
| `receiver.address` | لا | نص | | عنوان المشتري. |
| `lines` | نعم | مصفوفة، عنصر واحد على الأقل | | أسطر المستند، مرقمة 1، 2، 3 بترتيبها. |
| `lines.*.description` | نعم | نص | | ما بيع. |
| `lines.*.item_type` | لا | `EGS` أو `GS1` | | نظام الترميز، ويُطبع صغيراً فوق كود الصنف. |
| `lines.*.item_code` | لا | نص | | كود الصنف في EGS أو GS1. |
| `lines.*.unit` | لا | نص | | كود الوحدة كما هو مسجل، مثل `EA` أو `MON` أو `BOX`؛ ويُطبع كما هو. |
| `lines.*.quantity` | نعم | رقم | | الكمية. |
| `lines.*.unit_price` | نعم | رقم | | سعر الوحدة قبل الضرائب. |
| `lines.*.discount` | لا | رقم، صفر أو أكثر | | مبلغ يُخصم من السطر قبل الضرائب، ولا يزيد على الكمية × سعر الوحدة. |
| `lines.*.taxes` | لا | مصفوفة | | ضرائب السطر، انظر [الضرائب](#taxes). |
| `lines.*.taxes.*.type` | نعم، لكل ضريبة | من `T1` إلى `T20` (ويصلح `t1` أيضاً) | | نوع الضريبة في المنظومة. |
| `lines.*.taxes.*.rate` | لا | رقم | | نسبة مئوية من وعاء الضريبة. |
| `lines.*.taxes.*.amount` | لا | رقم | | مبلغ ثابت بدلاً من النسبة (ويُقدَّم على `rate`). |
| `lines.*.taxes.*.subtype` | لا | نص، حتى 20 حرفاً | `V009` للنوع T1 | النوع الفرعي في المنظومة، مثل `W010`. يبقى مع الضريبة في البيانات ولا يُطبع. |
| `extra_discount` | لا | رقم، صفر أو أكثر | `0` | خصم على المستند كله، يُطرح من الإجمالي بعد الضرائب. |
| `qr` | لا | نص | رابط البوابة | يستبدل محتوى رمز QR. وبدونه يفتح الرمز البوابة إن وُجد `uuid` و `long_id`. |
| `notes` | لا | نص | | ملاحظات في آخر المستند. |

الحقل الذي له قيمة افتراضية يُملأ قبل التحقق من البيانات، فيمكنك تركه حتى لو كان إلزامياً.

### القيم المحسوبة {#computed}

| القيمة | طريقة حسابها |
| --- | --- |
| `lines.*.sales` | الكمية × سعر الوحدة |
| `lines.*.net` | المبيعات ناقص خصم السطر |
| `lines.*.taxes` | كل ضريبة ومعها `amount` المحسوب، مرتبة حسب النوع (T1، T2 ...) |
| `lines.*.vat` | قيمة T1 في السطر: عمود «ض.ق.م» |
| `lines.*.total` | الصافي مع كل الضرائب ناقص T4: عمود «الإجمالي» |
| `totals.sales` و `totals.discount` و `totals.net` | المجاميع على كل الأسطر |
| `totals.taxes` | إجمالي كل نوع ضريبة، مثل `['T1' => 4200, 'T4' => 750]` |
| `totals.extra_discount` | قيمة `extra_discount` مقربة |
| `totals.total` | مجموع إجماليات الأسطر ناقص `extra_discount` |
| `qr` | `https://invoicing.eta.gov.eg/documents/{uuid}/share/{long_id}` إن لم تمرره |

تُحسب مبالغ الضرائب بخمس خانات عشرية كما تفعل المنظومة، وتُطبع بخانات العملة. ويتبع التفقيط لغة المستند: تفقيط عربي في العربية، وفي الإنجليزية يُكتب الرقم بالحروف عبر إضافة `intl` في PHP («thirty-three thousand four hundred fifty EGP only»). وبدون `intl` تحذف المستندات الإنجليزية هذا السطر.

### قيم الهوية {#theme}

| مفتاح الهوية | استخدامه |
| --- | --- |
| `logo` | فوق اسم البائع أعلى الصفحة |
| `primary` | اسم البائع والعنوان ورأس الجدول وسطر الإجمالي |
| `muted` | العناوين الصغيرة والعنوان البريدي ونص رمز QR |
| `border` | خانتا البائع والمشتري |

البائع يأتي من `issuer`، لا من بيانات الشركة في الهوية.

## الأشكال والخيارات {#options}

### أنواع المستند {#document-types}

| `document.type` | العنوان العربي | العنوان الإنجليزي |
| --- | --- | --- |
| `I` | فاتورة ضريبية إلكترونية | E-Invoice |
| `C` | إشعار دائن | Credit Note |
| `D` | إشعار مدين | Debit Note |

يغيّر النوع العنوان وتذييل الصفحة. وتُطبع المبالغ كما تمررها، فيعرض الإشعار الدائن الكميات والأسعار المردودة أرقاماً موجبة، كما في مستند المنظومة.

### أنواع المشتري {#receiver-types}

| `receiver.type` | من هو | عنوان `receiver.id` |
| --- | --- | --- |
| `B` | شركة مسجلة في مصر | رقم التسجيل الضريبي / Tax registration no. |
| `P` | شخص | الرقم القومي / National ID |
| `F` | مشترٍ أجنبي | رقم جواز السفر / Passport no. |

```php
'document' => ['type' => 'C', /* ... */],
'receiver' => [
    'type' => 'P',
    'id' => '29001011234567',
    'name' => 'أحمد عبد الرحمن',
],
```

أما البائع فيعرض دائماً رقم تسجيله الضريبي وكود الفرع وكود النشاط.

### الضرائب {#taxes}

يذكر كل سطر ضرائبه بنوعها في المنظومة، مع `rate` (نسبة مئوية) أو `amount` (مبلغ ثابت). ويحسبها القالب بالترتيب الذي تتبعه المنظومة:

| الأنواع | الاسم | الوعاء | أثرها في الإجمالي |
| --- | --- | --- | --- |
| T1 | ضريبة القيمة المضافة | الصافي + T2 + T3 + الرسوم الخاضعة (T5 إلى T12) | تُضاف |
| T2 | ضريبة الجدول (نسبية) | الصافي + T3 + الرسوم الخاضعة (T5 إلى T12) | تُضاف |
| T3 | ضريبة الجدول (قطعية) | الصافي (وتُمرر عادة بـ `amount`) | تُضاف |
| T4 | الخصم تحت حساب الضريبة | الصافي | تُخصم |
| T5 إلى T12 | ضريبة الدمغة، ضريبة الملاهي، رسم تنمية الموارد، رسم الخدمة، رسم المحليات، رسم التأمين الصحي، رسوم أخرى | الصافي | تُضاف، وتدخل في وعاء T1 و T2 |
| T13 إلى T20 | الضرائب والرسوم نفسها التي في T5 إلى T12 حين لا تكون خاضعة، بالأسماء نفسها | الصافي | تُضاف فقط |

هنا سطر بضاعة عليه ضريبة جدول قطعية وضريبة جدول نسبية وضريبة قيمة مضافة، وسطر خدمة عليه ضريبة قيمة مضافة وخصم تحت حساب الضريبة 1%:

```php
'lines' => [
    [
        'description' => 'مياه غازية - عبوة 330 مل',
        'item_type' => 'GS1',
        'item_code' => '6223001234567',
        'unit' => 'BOX',
        'quantity' => 10,
        'unit_price' => 120,
        'taxes' => [
            ['type' => 'T3', 'amount' => 50],  // ضريبة جدول قطعية
            ['type' => 'T2', 'rate' => 8],     // ضريبة جدول: الصافي + T3
            ['type' => 'T1', 'rate' => 14],    // القيمة المضافة: الصافي + T2 + T3
        ],
    ],
    [
        'description' => 'خدمة توريد وتركيب',
        'item_type' => 'EGS',
        'item_code' => 'EG-123456789-3003',
        'unit' => 'EA',
        'quantity' => 1,
        'unit_price' => 2000,
        'taxes' => [
            ['type' => 'T1', 'rate' => 14],
            ['type' => 'T4', 'subtype' => 'W010', 'rate' => 1],  // تُخصم
        ],
    ],
],
```

السطر الأول: الصافي 1,200.00، و T3 بقيمة 50.00، و T2 بنسبة 8% من 1,250 أي 100.00، و T1 بنسبة 14% من 1,350 أي 189.00، والإجمالي 1,539.00. والثاني: 2,000 مع ضريبة 280.00 ناقص خصم 20.00 = 2,260.00. ويعرض الملخص T1 بقيمة 469.00، و T2 بقيمة 100.00، و T3 بقيمة 50.00، و T4 بقيمة ‎-20.00.

عمود «ض.ق.م» في السطر يعرض T1 فقط؛ وتظهر كل ضريبة أخرى في الملخص بنوعها واسمها، مثل `T13 - ضريبة الدمغة (نسبية)`.

### الإجماليات والخصم الإضافي {#totals}

يُقرأ الملخص تحت الأسطر بهذا الترتيب: إجمالي المبيعات، ثم إجمالي الخصومات (إن وُجدت)، ثم صافي المبيعات، ثم سطر لكل نوع ضريبة، ثم الخصم الإضافي (إن وُجد)، ثم إجمالي الفاتورة. يُطرح `extra_discount` بعد الضرائب، فلا يغيّر أي ضريبة.

### رمز QR {#qr}

مع `document.uuid` و `document.long_id` يفتح الرمز المستند على بوابة مصلحة الضرائب، وتحته «امسح الرمز للتحقق من الفاتورة على بوابة مصلحة الضرائب». مرّر `qr` لتضع فيه محتوى آخر. وبدون `qr` وبدون المعرّفين لا يُطبع رمز، وهذا يناسب مسودة تُطبع قبل الإرسال.

### وقت الإصدار {#issue-time}

تعطي المنظومة `dateTimeIssued` بتوقيت UTC، مثل `2026-10-08T09:45:00Z`. ويطبعه القالب بالمنطقة الزمنية للتطبيق (`timezone` في `config/app.php`): 2026/10/08 12:45 مع `Africa/Cairo`. والوقت الذي بلا منطقة زمنية يُطبع كما هو.

## ملف Word {#word}

يبني `layout.php` ملف PDF وملف Word معاً، فلهما المحتوى نفسه بالترتيب نفسه. ملخص الضرائب جزء من جدول الإجماليات في الصيغتين، ورمز QR يأتي بعد التفقيط. ويحتفظ تذييل الصفحة بنوع المستند ورقمه و«صفحة X من Y» بحقول أرقام صفحات Word.

ملف Word بلا علامة مائية، ويرفض `->word()` أي مستند عليه `->password()`. ملفات Word تحتاج الحزمة `phpoffice/phpword`؛ انظر [ملفات Word](/ar/guide/word).

## خصّصه {#customise}

```bash
php artisan doc:template eg-invoice --as=my-eg-invoice
```

ينسخ هذا الأمر القالب إلى `resources/doc-templates/my-eg-invoice`. استخدمه بـ `Doc::template('my-eg-invoice', $data)` وعدّل:

- `lang/ar.php` و `lang/en.php` للعناوين: أسماء المستندات تحت `types`، وأسماء الضرائب تحت `tax_types`، ونص رمز QR تحت `verify`.
- `layout.php` لتخطيط الصيغتين: أعمدة جدول الأسطر وما تعرضه الخانات.
- `template.php` للحقول وحساب الضرائب في `prepare()`.
- `footer.blade.php` لتذييل الصفحة.

انظر [قوالبك الخاصة](/ar/guide/custom-templates).
