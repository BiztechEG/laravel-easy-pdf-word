# سند قبض وسند صرف

سند القبض هو ما يسلّمه أمين الخزينة أو المحاسب لمن يدفع مبلغاً للشركة، وسند الصرف يوثّق مبلغاً تدفعه الشركة لغيرها. يطبع القالب `receipt` أيّاً منهما على صفحة A5 بالعرض، مع المبلغ بالأرقام وكتابةً، وطريقة الدفع، وخانات التوقيع.

## متى تستخدمه {#when-to-use}

- يدفع عميل قسطاً من فاتورة نقداً أو بشيك في مقر الشركة، فيطبع له أمين الخزينة سند قبض يحتفظ به.
- يسجّل تطبيقك تحويلاً بنكياً من عميل، ويرسل إليه سند قبض بالبريد مع رقم التحويل.
- يدفع القسم المالي لمورد أو مقاول، ويحتاج إلى سند صرف موقّع لملف المصروفات.
- تحصّل مدرسة أو عيادة الرسوم عند الشباك، وتطبع سنداً فيه المبلغ مكتوباً بالحروف.
- العُهد النقدية والسُّلف: يستلم موظف سلفة ويوقّع على سند الصرف بصفته المستلِم.

## مثال سريع {#example}

مرّر بيانات السند إلى القالب وحدّد اللغة:

```php
use BiztechEG\EasyPdfWord\Facades\Doc;

$voucher = Doc::template('receipt', [
    'type' => 'receipt',
    'number' => 'RV-2026-0315',
    'date' => '2026-10-08',
    'amount' => 15750.50,
    'currency' => 'EGP',
    'party' => 'مؤسسة النور للتجارة',
    'for' => 'الدفعة الثانية من قيمة عقد تطوير نظام إدارة المخزون',
    'method' => 'cheque',
    'cheque' => [
        'number' => '00045871',
        'bank' => 'البنك الأهلي المصري',
        'date' => '2026-10-15',
    ],
    'notes' => 'يعتبر هذا السند لاغياً في حالة عدم صرف الشيك.',
])->locale('ar');
```

ثم أعِد من الـ controller الملف الذي تحتاجه:

::: code-group

```php [PDF]
return $voucher->pdf()->download('RV-2026-0315.pdf');
```

```php [Word]
return $voucher->word()->download('RV-2026-0315.docx');
```

:::

النتيجة صفحة واحدة A5 بالعرض، مثل المعاينة أعلاه:

- العنوان سند قبض، ورقم السند وتاريخه في الركن؛
- المبلغ داخل إطار `المبلغ: 15,750.50 ج.م`، ثم كتابةً: فقط خمسة عشر ألفاً وسبعمائة وخمسون جنيهاً وخمسون قرشاً لا غير؛
- سطر طريقة الدفع: شيك - رقم الشيك: 00045871 - البنك: البنك الأهلي المصري - تاريخ الاستحقاق: 2026/10/15؛
- ثلاث خانات للتوقيع: المسلِّم، أمين الخزينة، المحاسب.

اسم الشركة وعنوانها وشعارها في الأعلى تأتي من الهوية (انظر [قيم الهوية](#theme) أدناه). ومع `->locale('en')` تظهر البيانات نفسها بعناوين إنجليزية، ويُكتب المبلغ "fifteen thousand seven hundred fifty EGP and 50/100 only" (الكتابة بالإنجليزية تحتاج إلى إضافة PHP المسماة `intl`).

## الحقول {#fields}

يجري التحقق من البيانات قبل رسم أي شيء، والحقل الناقص أو الخاطئ يرمي `ValidationException`. ويمكن ترك الحقول التي لها قيمة افتراضية.

| الحقل | مطلوب | النوع أو القيم | القيمة الافتراضية | الوظيفة |
| --- | --- | --- | --- | --- |
| `type` | نعم | `receipt` أو `payment` | `receipt` | سند قبض (مبلغ وارد) أو سند صرف (مبلغ صادر). يحدد العنوان والعبارة قبل `party` والتوقيعات الافتراضية. |
| `number` | نعم | نص | | رقم السند، بجوار العنوان، ويبقى من اليسار إلى اليمين. |
| `date` | نعم | تاريخ | | تاريخ السند، ويُطبع بالشكل `2026/10/08`. |
| `amount` | نعم | رقم، 0 أو أكثر | | المبلغ. يُقرَّب إلى عدد الخانات العشرية للعملة، ثم يُطبع بالأرقام (داخل الإطار) وكتابةً. |
| `currency` | نعم | رمز من 3 أحرف | `EGP` | يحدد الخانات العشرية، والاختصار (ج.م، ر.س ...) واسم العملة في التفقيط. |
| `party` | نعم | نص | | من دفع لك (استلمنا من) أو من دفعتَ له (صرفنا إلى). |
| `for` | نعم | نص | | سبب الدفع (وذلك عن). |
| `method` | نعم | `cash` أو `cheque` أو `transfer` أو `card` | `cash` | طريقة الدفع. |
| `cheque.number` | عندما تكون `method` هي `cheque` | نص | | رقم الشيك، ويُضاف إلى سطر طريقة الدفع. |
| `cheque.bank` | لا | نص | | البنك المسحوب عليه الشيك. |
| `cheque.date` | لا | تاريخ | | تاريخ استحقاق الشيك. |
| `reference` | لا | نص | | رقم التحويل أو عملية البطاقة. يضيف صفاً بعنوان "رقم المرجع"، من اليسار إلى اليمين. |
| `notes` | لا | نص | | ملاحظة صغيرة رمادية تحت البيانات. |
| `signatures` | لا | قائمة نصوص | انظر [خانات التوقيع](#signatures) | خانات التوقيع بالترتيب. |

لا تُطبع بيانات `cheque` إلا عندما تكون `method` هي `cheque`.

### قيم الهوية {#theme}

يقرأ القالب أيضاً قيم الهوية التالية، وتضبطها مرة واحدة في `config/easy-pdf-word.php` أو لكل مستند عبر `->theme([...])` (انظر [الإعدادات](/ar/guide/configuration)):

| مفتاح الهوية | مكان ظهوره |
| --- | --- |
| `company.name` | الركن العلوي، بخط عريض وباللون الأساسي. |
| `company.address` | تحت اسم الشركة، بخط صغير رمادي. |
| `logo` | فوق اسم الشركة، بعرض 25 مم. انظر [الصور](/ar/guide/images) لمعرفة المجلدات المسموح بها. |
| `primary` | العنوان، والخط تحت الرأس، وإطار المبلغ، وخلفيته درجة فاتحة من اللون نفسه. |
| `muted` | العنوان البريدي، والملاحظات، وخطوط التوقيع. |
| `border` | خطوط جدول البيانات. |

```php
Doc::template('receipt', $data)
    ->theme([
        'primary' => '#1D4ED8',
        'logo' => public_path('images/logo.png'),
        'company' => [
            'name' => 'شركة بيزتك للحلول البرمجية',
            'address' => '15 شارع التحرير، الدقي، الجيزة',
        ],
    ])
    ->locale('ar')
    ->pdf();
```

## الأنواع والخيارات {#options}

### سند قبض أو سند صرف {#receipt-or-payment}

الحقل `type` يبدّل بين المستندين:

| | `receipt` | `payment` |
| --- | --- | --- |
| العنوان | سند قبض / Receipt Voucher | سند صرف / Payment Voucher |
| العبارة قبل `party` | استلمنا من / Received from | صرفنا إلى / Paid to |
| التوقيعات الافتراضية | `payer` و`cashier` و`accountant` | `receiver` و`accountant` و`manager` |

سند صرف لمورد دُفع له بتحويل بنكي:

```php
$voucher = Doc::template('receipt', [
    'type' => 'payment',
    'number' => 'PV-2026-0088',
    'date' => '2026-10-12',
    'amount' => 4200,
    'currency' => 'SAR',
    'party' => 'مؤسسة الريان للصيانة',
    'for' => 'صيانة أجهزة التكييف في فرع الرياض عن شهر سبتمبر',
    'method' => 'transfer',
    'reference' => 'TRF-88231940',
])->locale('ar');
```

يطبع العنوان سند صرف، و`المبلغ: 4,200.00 ر.س`، والتفقيط فقط أربعة آلاف ومائتا ريال لا غير، وطريقة الدفع تحويل بنكي، وصف رقم المرجع بالقيمة `TRF-88231940`، وخانات التوقيع المستلِم، المحاسب، المدير المالي.

### طرق الدفع {#payment-methods}

| `method` | بالعربية | بالإنجليزية | ما يُطبع معها |
| --- | --- | --- | --- |
| `cash` | نقداً | Cash | |
| `cheque` | شيك | Cheque | رقم الشيك (مطلوب)، ثم البنك وتاريخ الاستحقاق إن وُجدا. |
| `transfer` | تحويل بنكي | Bank transfer | مرّر `reference` لرقم التحويل. |
| `card` | بطاقة | Card | مرّر `reference` لرقم عملية البطاقة. |

يعمل `reference` مع أي طريقة دفع، ويضيف صفاً خاصاً به تحت طريقة الدفع.

### خانات التوقيع {#signatures}

الحقل `signatures` قائمة بالأدوار، تُطبع متجاورة بالترتيب الذي تحدده. الأدوار التالية تُترجم، وأي نص آخر يُطبع كما كتبته:

| الدور | بالعربية | بالإنجليزية |
| --- | --- | --- |
| `payer` | المسلِّم | Paid by |
| `receiver` | المستلِم | Received by |
| `cashier` | أمين الخزينة | Cashier |
| `accountant` | المحاسب | Accountant |
| `manager` | المدير المالي | Finance manager |

```php
$data['signatures'] = ['payer', 'cashier', 'مدير الفرع'];
```

يطبع هذا ثلاث خانات: المسلِّم، أمين الخزينة، مدير الفرع.

### العملة والخانات العشرية والتفقيط {#currency}

- يُقرَّب المبلغ إلى عدد الخانات العشرية للعملة: خانتان لمعظم العملات، و3 خانات للعملات `KWD` و`BHD` و`OMR` و`JOD` و`IQD` و`LYD` و`TND`، وبلا كسور للعملتين `JPY` و`KRW`. فالمبلغ `1250.125` بعملة `KWD` يُطبع `1,250.125 د.ك`.
- في المستندات العربية تظهر اختصارات العملات `EGP` و`SAR` و`AED` و`KWD` و`QAR` و`BHD` و`OMR` و`JOD` و`USD` و`EUR` (ج.م، ر.س، د.إ ...)، أما بقية الرموز، وكل الرموز في المستندات الإنجليزية، فتُطبع كما هي.
- يذكر التفقيط العربي اسم العملة للعملات `EGP` و`SAR` و`AED` و`QAR` و`KWD` و`USD` و`EUR`، ولغيرها يُكتب الرقم بالحروف متبوعاً برمز العملة. ويمكنك إضافة عملات في ملف الإعدادات؛ انظر [دعم اللغة العربية](/ar/guide/arabic).

### مقاس الورق {#paper}

السند افتراضياً على ورق A5 بالعرض. لطباعته على A4:

```php
Doc::template('receipt', $data)->paper('A4', 'portrait')->locale('ar')->pdf();
```

أما `->paper('A4')` وحدها فتُبقي اتجاه القالب بالعرض. المزيد في [إعدادات الصفحة](/ar/guide/page-settings).

## ملف Word {#word}

للسند ملف `layout.php` واحد يبني الملفين معاً، لذلك يحمل ملف Word محتوى ملف PDF نفسه: الرأس مع الشعار، وإطار المبلغ، وجدول البيانات، والملاحظات، وخانات التوقيع، على صفحة A5 بالعرض. ولا يوجد تذييل صفحة في أي من الصيغتين.

ملفات Word تحتاج إلى الحزمة `phpoffice/phpword`، وتستخدم خطاً مثبتاً على جهاز القارئ (Arial افتراضياً). انظر [ملفات Word](/ar/guide/word).

## تخصيص القالب {#customise}

انسخ القالب إلى مشروعك وعدّل النسخة:

```bash
php artisan doc:template receipt --as=my-receipt
```

ينشئ هذا الأمر المجلد `resources/doc-templates/my-receipt/` وفيه:

- `template.php`: الحقول، والقيم الافتراضية (مثل `'currency' => 'SAR'`)، ومقاس الورق؛
- `layout.php`: التخطيط، ويُستخدم لملف PDF وملف Word معاً؛
- `lang/ar.php` و`lang/en.php`: كل العناوين، مثل اسمي السندين وأدوار التوقيع.

ثم استخدم النسخة باسمها الجديد: `Doc::template('my-receipt', $data)`. ومن دون `--as` تحتفظ النسخة بالاسم `receipt` وتحل محل القالب المرفق مع الحزمة في تطبيقك. انظر [قوالبك الخاصة](/ar/guide/custom-templates).
