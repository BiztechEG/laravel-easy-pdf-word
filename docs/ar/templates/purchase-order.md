# أمر شراء

قالب `purchase-order` هو أمر الشراء الذي ترسله الشركة إلى المورد: ما المطلوب توريده وبأي سعر، وأين ومتى يُسلَّم، وشروط الدفع، مع خانات توقيع لمن أعدّه ومن اعتمده ولموافقة المورد.

## متى تستخدمه {#when-to-use}

- إدارة المشتريات تطلب أدوات مكتبية أو قطع غيار من مورد، بأكواد الأصناف ووحداتها.
- عرض سعر معتمد من مورد يتحول إلى أمر شراء يشير إليه.
- البضاعة يجب أن تصل إلى مخزن أو فرع غير المقر الرئيسي، في موعد محدد.
- الأمر يحتاج توقيع مقدم الطلب والمدير، ويوقّع المورد بالموافقة عليه.
- المورد يطلب الأمر ملف Word ليدخله في نظامه.

## مثال سريع {#example}

أمر الشراء الذي في المعاينة أعلاه، وشركتك في رأسه، محفوظاً ملف PDF وملف Word:

```php
use BiztechEG\EasyPdfWord\Facades\Doc;

$order = Doc::template('purchase-order', [
    'order' => [
        'number' => 'PO-2026-0412',
        'date' => '2026-10-08',
        'delivery_date' => '2026-10-20',
        'currency' => 'EGP',
        'tax_rate' => 14,
        'reference' => 'QT-5531',
        'payment_terms' => 'الدفع بتحويل بنكي خلال 30 يوماً من الاستلام وتقديم الفاتورة الضريبية.',
    ],
    'supplier' => [
        'name' => 'شركة الأمل لتوريد مستلزمات المكاتب',
        'contact' => 'الأستاذة منى سامي',
        'phone' => '+20 2 2345 6789',
        'address' => 'المنطقة الصناعية الثالثة، العاشر من رمضان',
        'tax_number' => '456-789-123',
    ],
    'delivery' => [
        'address' => 'المخزن الرئيسي، 15 شارع التحرير، الدقي، الجيزة',
        'contact' => 'محمود علي (أمين المخزن)',
        'phone' => '+20 100 111 2222',
    ],
    'items' => [
        ['code' => 'PPR-A4-80', 'description' => 'ورق طباعة A4 وزن 80 جم', 'unit' => 'كرتونة', 'quantity' => 40, 'unit_price' => 950],
        ['code' => 'TNR-26A', 'description' => 'حبر طابعة HP 26A أصلي', 'unit' => 'قطعة', 'quantity' => 10, 'unit_price' => 3200, 'discount' => 1500],
        ['code' => 'CHR-ERG-01', 'description' => 'كرسي مكتب طبي بمسند ظهر', 'unit' => 'قطعة', 'quantity' => 6, 'unit_price' => 4750],
    ],
    'terms' => [
        'يتم التوريد دفعة واحدة إلى عنوان التسليم الموضح.',
        'يحق للشركة رفض أي صنف مخالف للمواصفات أو تالف عند الاستلام.',
        'يجب ذكر رقم أمر الشراء على الفاتورة وإذن التسليم.',
    ],
])
    ->theme([
        // أو مرة واحدة للتطبيق كله، تحت "theme" في config/easy-pdf-word.php
        'company' => [
            'name' => 'شركة بيزتك للحلول البرمجية',
            'address' => '15 شارع التحرير، الدقي، الجيزة',
            'phone' => '+20 100 000 0000',
            'tax_number' => '123-456-789',
        ],
    ])
    ->locale('ar');

// ملف PDF
$order->pdf()->save(storage_path('app/purchase-orders/PO-2026-0412.pdf'));

// الأمر نفسه ملف Word
$order->word()->save(storage_path('app/purchase-orders/PO-2026-0412.docx'));
```

يعرض الأمر مجموعاً قدره 98,500.00 وخصماً قدره ‎-1,500.00 وصافياً قدره 97,000.00 وضريبة (14%) قدرها 13,580.00 وإجمالياً قدره 110,580.00 ج.م، ثم «فقط مائة وعشرة آلاف وخمسمائة وثمانون جنيهاً لا غير»، وشروط الدفع، والشروط، وثلاث خانات توقيع: «أعدّه» و«اعتمده» و«موافقة المورد».

وفي الـ controller يرسل `return $order->pdf()->download('PO-2026-0412.pdf');` الملف إلى المتصفح بدلاً من حفظه. انظر [الإخراج والتسليم](/ar/guide/output).

## الحقول {#fields}

| الحقل | إلزامي | النوع / القيم | القيمة الافتراضية | الوظيفة |
| --- | --- | --- | --- | --- |
| `order.number` | نعم | نص أو رقم | | رقم الأمر، أعلى الصفحة وفي تذييل الصفحة. |
| `order.date` | نعم | تاريخ | | تاريخ الأمر. |
| `order.delivery_date` | لا | تاريخ | | تاريخ التوريد المطلوب، ويُطبع بخط عريض في الرأس. |
| `order.currency` | نعم | رمز من 3 أحرف | `EGP` | عملة كل المبالغ: الخانات العشرية والاختصار بعد الإجمالي والتفقيط. |
| `order.tax_rate` | لا | رقم، صفر أو أكثر | `0` | نسبة ضريبة القيمة المضافة على الصافي بعد الخصم. عند الصفر لا يظهر سطر الضريبة. |
| `order.reference` | لا | نص | | رقم عرض السعر من المورد، ويُطبع بعد «مرجع عرض السعر» / "Quotation ref.". |
| `order.payment_terms` | لا | نص | | شروط الدفع، وتُطبع بعد الإجماليات. |
| `supplier.name` | نعم | نص | | المورد، في خانة «المورد» / "Supplier". |
| `supplier.contact` | لا | نص | | المسؤول لدى المورد. |
| `supplier.phone` | لا | نص | | هاتف المورد، ويُكتب من اليسار إلى اليمين. |
| `supplier.address` | لا | نص | | عنوان المورد. |
| `supplier.tax_number` | لا | نص | | الرقم الضريبي للمورد. |
| `delivery.address` | لا | نص | `company.address` في الهوية | مكان التسليم، في خانة «جهة التسليم» / "Deliver to". |
| `delivery.contact` | لا | نص | | من يستلم البضاعة. |
| `delivery.phone` | لا | نص | | الهاتف في مكان التسليم. |
| `items` | نعم | مصفوفة، عنصر واحد على الأقل | | الأصناف المطلوبة، مرقمة 1، 2، 3. |
| `items.*.code` | لا | نص | | كود الصنف؛ ويظهر عمود الكود فقط عندما يكون لصنف ما كود. |
| `items.*.description` | نعم | نص | | الصنف. |
| `items.*.unit` | لا | نص | | الوحدة، مثل «كرتونة» أو «قطعة». |
| `items.*.quantity` | نعم | رقم، صفر أو أكثر | | الكمية المطلوبة. |
| `items.*.unit_price` | نعم | رقم | | سعر الوحدة المتفق عليه قبل الضريبة. |
| `items.*.discount` | لا | رقم، صفر أو أكثر | | مبلغ يُخصم من هذا السطر؛ ويظهر عمود الخصم فقط عندما يكون في سطر ما خصم. |
| `terms` | لا | مصفوفة نصوص | `[]` | الشروط، وتُطبع قائمة مرقمة. |
| `notes` | لا | نص | | ملاحظات بعد الشروط. |
| `signatures` | لا | مصفوفة نصوص | `prepared_by` و `approved_by` و `supplier` | خانات التوقيع بترتيبها. انظر [التوقيعات](#signatures). |

الحقل الذي له قيمة افتراضية يُملأ قبل التحقق من البيانات، فيمكنك تركه حتى لو كان إلزامياً.

### القيم المحسوبة {#computed}

| القيمة | طريقة حسابها |
| --- | --- |
| `items.*.total` | الكمية × سعر الوحدة، مقربة لخانات العملة، ناقص خصم السطر |
| `totals.subtotal` | مجموع الكمية × سعر الوحدة |
| `totals.discount` | مجموع خصومات الأسطر |
| `totals.net` | المجموع ناقص الخصم |
| `totals.tax` | الصافي × `tax_rate` / 100، مقرباً |
| `totals.total` | الصافي مع الضريبة: «إجمالي أمر الشراء» |
| `signatures` | الخانات الثلاث الافتراضية إن لم تمرر شيئاً |

ويتبع التفقيط لغة المستند: تفقيط عربي في العربية، وفي الإنجليزية يُكتب الرقم بالحروف عبر إضافة `intl` في PHP. وبدون `intl` تحذف المستندات الإنجليزية هذا السطر.

### قيم الهوية {#theme}

| مفتاح الهوية | استخدامه |
| --- | --- |
| `company.name` و `company.address` و `company.phone` و `company.tax_number` | شركتك أعلى الصفحة. و `company.address` هو أيضاً مكان التسليم عندما يكون `delivery.address` فارغاً. |
| `logo` | فوق اسم الشركة |
| `primary` | اسم الشركة والعنوان ورأس الجدول وسطر الإجمالي |
| `muted` | العنوان البريدي والعناوين الصغيرة وخطوط التوقيع المنقطة |
| `border` | خانتا المورد وجهة التسليم |

## الأشكال والخيارات {#options}

### التوقيعات {#signatures}

يحدد `signatures` الخانات في أسفل الأمر، من اليمين إلى اليسار في العربية ومن اليسار إلى اليمين في الإنجليزية. ثلاث قيم تُترجم، وأي نص آخر يُطبع كما هو:

| القيمة | بالعربية | بالإنجليزية |
| --- | --- | --- |
| `prepared_by` | أعدّه | Prepared by |
| `approved_by` | اعتمده | Approved by |
| `supplier` | موافقة المورد | Supplier acceptance |

```php
'signatures' => ['prepared_by', 'approved_by', 'مدير المشتريات'],
```

مرّر مصفوفة فارغة، `'signatures' => []`، لأمر بلا خانات توقيع.

### مكان التسليم {#delivery}

تعرض خانة «جهة التسليم» قيمة `delivery.address`، أو عنوان شركتك من الهوية إن تركتها، وتحته اسم المستلم وهاتفه.

### بضريبة أو بدونها {#vat}

القيمة الافتراضية لـ `order.tax_rate` صفر، فلا يظهر سطر الضريبة حتى تضبط نسبة. ومع الخصم تضيف الإجماليات الخصم والصافي بعد الخصم، ومع الضريبة سطرها، ثم إجمالي الأمر.

### أعمدة تظهر عند الحاجة {#columns}

يظهر عمود الكود فقط عندما يكون لصنف واحد على الأقل `code`، وعمود الخصم فقط عندما يكون في سطر ما `discount`. ويأخذ عمود الصنف العرض الذي تتركه بقية الأعمدة.

## ملف Word {#word}

يبني `layout.php` ملف PDF وملف Word معاً، فلهما المحتوى نفسه بالترتيب نفسه. ويحتفظ تذييل الصفحة بالعنوان ورقم الأمر و«صفحة X من Y» بحقول أرقام صفحات Word.

ملف Word بلا علامة مائية، ويرفض `->word()` أي مستند عليه `->password()`. ملفات Word تحتاج الحزمة `phpoffice/phpword`؛ انظر [ملفات Word](/ar/guide/word).

## خصّصه {#customise}

```bash
php artisan doc:template purchase-order --as=my-purchase-order
```

ينسخ هذا الأمر القالب إلى `resources/doc-templates/my-purchase-order`. استخدمه بـ `Doc::template('my-purchase-order', $data)` وعدّل:

- `lang/ar.php` و `lang/en.php` للعناوين: الجملة الافتتاحية تحت `intro`، وأسماء التوقيعات تحت `signatures` (أضف أدوارك هناك لتُترجم).
- `template.php` للحقول والقيم الافتراضية (العملة ونسبة الضريبة) والتوقيعات الافتراضية في `prepare()`.
- `layout.php` لتخطيط الصيغتين.
- `footer.html.php` لتذييل الصفحة.

انظر [قوالبك الخاصة](/ar/guide/custom-templates).
