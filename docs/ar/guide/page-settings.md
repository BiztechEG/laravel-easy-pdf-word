# إعدادات الصفحة

حدّد مقاس الورق واتجاهه والهوامش ورأس الصفحة وتذييلها، واطبع علامة مائية على صفحات المستند، أو احمِ ملف PDF بكلمة مرور.

## مقاس الورق واتجاهه {#paper}

```php
use BiztechEG\EasyPdfWord\Facades\Doc;

Doc::template('report', $data)->paper('A3')->landscape()->pdf();

Doc::template('receipt', $data)->paper('A5', 'landscape')->pdf();

Doc::template('report', $data)->paper('A4-L')->pdf();   // A4 بالعرض، كما يكتبه mPDF
```

| الاسم | المقاس (مم) |
| --- | --- |
| `A2` | 420 × 594 |
| `A3` | 297 × 420 |
| `A4` | 210 × 297 |
| `A5` | 148 × 210 |
| `A6` | 105 × 148 |
| `B4` | 250 × 353 |
| `B5` | 176 × 250 |
| `Letter` | 215.9 × 279.4 |
| `Legal` | 215.9 × 355.6 |
| `Tabloid` | 279.4 × 431.8 |
| `Executive` | 184.15 × 266.7 |

- لا فرق بين الأحرف الكبيرة والصغيرة في الأسماء: `a4` و`letter`.
- تحدد `->landscape()` و`->portrait()` الاتجاه (بالعرض أو بالطول). و`->paper('A5', 'landscape')` تفعل الأمرين في استدعاء واحد.
- الاسم المنتهي بـ `-L` أو `-P` (`A4-L` و`Letter-P`) يحمل الاتجاه أيضًا، في `->paper()` وفي `template.php` وفي ملف الإعدادات.
- الاسم غير المعروف يرمي خطأ فورًا: `Unknown paper size [Foolscap]. Use one of A2, A3, A4, A5, A6, B4, B5, LETTER, LEGAL, TABLOID, EXECUTIVE, or [width, height] in mm.`

وتنطبق الإعدادات نفسها على ملفات Word المنشأة من المستند: تأخذ صفحة Word المقاس والاتجاه والهوامش نفسها.

### مقاس مخصص {#custom-paper}

لمقاس غير موجود في القائمة، مثل ملصق أو إيصال طابعة حرارية، مرّر `[width, height]` بالمليمتر:

```php
Doc::view('pdf.till-receipt', ['order' => $order])->paper([80, 200])->pdf();
```

وتصلح المصفوفة نفسها قيمةً للمفتاح `paper` في ملف `template.php` للقالب، أو مقاسًا افتراضيًا للورق في `config/easy-pdf-word.php`:

```php
'pdf' => [
    'paper' => [80, 200],
    // ...
],
```

ويبقى الاتجاه ساريًا: في الوضع الطولي يكون الضلع الأقصر هو العرض، ومع `->landscape()` يكون الضلع الأطول هو العرض. والمقاس الذي ليس عددين موجبين يرمي `A paper size must be [width, height] in mm, for example [100, 150].`

## الهوامش {#margins}

الهوامش بالمليمتر، وتعمل مثل هوامش CSS:

```php
->margins(15)                // 15 من كل جانب
->margins(20, 15)            // 20 أعلى وأسفل، و15 يمين ويسار
->margins(25, 15, 20)        // 25 أعلى، و15 يمين ويسار، و20 أسفل
->margins(25, 15, 20, 10)    // أعلى، يمين، أسفل، يسار
```

ويقبل ملف الإعدادات وملف `template.php` للقالب الصيغ نفسها في صورة مصفوفات: `[15]` أو `[20, 15]` أو `[25, 15, 20]` أو `[25, 15, 20, 10]`.

اليمين واليسار هما جانبا الورقة الفعليان، في المستندات العربية أيضًا ومع كل المحركات: مع `->margins(15, 40, 15, 10)` يبقى 40 مم على اليمين و10 مم على اليسار.

## رأس الصفحة وتذييلها {#header-footer}

تأخذ `->header()` و`->footer()` نص HTML يُطبع في كل صفحة. ويتحول `{page}` و`{pages}` إلى رقم الصفحة وعدد الصفحات:

```php
Doc::template('report', $data)
    ->locale('ar')
    ->margins(30, 15, 20, 15)
    ->header('<div style="text-align: left; font-size: 9pt; color: #6B7280;">شركة بيزتك - تقرير داخلي</div>')
    ->footer('<div style="text-align: center; font-size: 9pt;">صفحة {page} من {pages}</div>')
    ->pdf();
```

- إن حددتهما هنا، حلّا محل ملفي رأس الصفحة والتذييل الخاصين بالقالب (`header.html.php` و`footer.html.php`). ولمعظم القوالب المرفقة تذييل فيه أرقام الصفحات.
- يطبع mPDF رأس الصفحة في الهامش العلوي والتذييل في الهامش السفلي، فاترك لهما مساحة في هذين الهامشين، كما تفعل `->margins(30, 15, 20, 15)` في المثال.
- يرسم Chromium وGotenberg رأس الصفحة وتذييلها منفصلين عن الصفحة، بخط المستند وبحجم صغير (9px). وتبقى الأنماط المكتوبة داخل HTML سارية.
- في ملفات Word يصبح رأس الصفحة وتذييلها نصًا عاديًا، ويتحول `{page}` و`{pages}` إلى حقول أرقام الصفحات في Word (انظر [ملفات Word](/ar/guide/word)).

### الأرقام العربية في رأس الصفحة وتذييلها {#header-digits}

مع `->numerals('arabic')` تتحول أيضًا الأرقام المكتوبة في نص رأس الصفحة وتذييلها. ويطبع mPDF كذلك `{page}` و`{pages}` بالأرقام العربية (١، ٢، ٣). أما Chromium وGotenberg فيطبعان `{page}` و`{pages}` بالأرقام اللاتينية دائمًا.

## العلامة المائية {#watermark}

تطبع `->watermark()` نصًا مائلًا عبر كل صفحة من صفحات ملف PDF:

```php
Doc::template('quotation', $data)->locale('ar')->watermark('مسودة')->pdf();

Doc::template('invoice', $data)->watermark('نسخة', opacity: 0.08, color: '#B91C1C')->pdf();
```

| الوسيط | القيمة الافتراضية | المعنى |
| --- | --- | --- |
| `$text` | | حتى 100 حرف. تُوصل الحروف العربية، وتتبع الأرقام `->numerals()`. والنص الفارغ يرمي خطأ. |
| `opacity` | `0.12` | من `0.01` (بالكاد يُرى) إلى `1` (معتم تمامًا). |
| `color` | `'#000000'` | أي لون CSS: `#B91C1C` أو `rgb(185, 28, 28)` أو `red`. وأي قيمة أخرى ترجع إلى الأسود. |

تُرسم العلامة المائية بخط المستند وبحجم يناسب الصفحة. وتعمل مع mPDF وChromium وGotenberg، أما ملفات Word فتُنشأ بدونها.

## كلمة المرور {#password}

تشفّر `->password()` ملف PDF:

```php
// تُطلب عند فتح الملف
Doc::template('payslip', $data)->locale('ar')->password('19870412')->pdf();

// يُفتح بلا كلمة مرور، لكن لا يُسمح للقارئ إلا بالطباعة
Doc::template('receipt', $data)->password('', owner: 'admin-secret', allow: ['print'])->pdf();
```

| الوسيط | القيمة الافتراضية | المعنى |
| --- | --- | --- |
| `$user` | | كلمة المرور المطلوبة لفتح الملف. و`''` تفتح الملف بدونها. |
| `owner` | عشوائية | كلمة المرور التي ترفع القيود المحددة في `allow`. وإن لم تحددها، تُستخدم كلمة مرور عشوائية، فلا يستطيع أحد رفع القيود. |
| `allow` | `['print', 'print-highres', 'copy']` | ما يُسمح للقارئ بفعله. |

الصلاحيات التي يمكنك وضعها في `allow`:

| الصلاحية | تسمح بـ |
| --- | --- |
| `print` | الطباعة |
| `print-highres` | الطباعة بالجودة الكاملة |
| `copy` | نسخ النصوص والصور |
| `modify` | تعديل المحتوى |
| `annot-forms` | إضافة التعليقات وتعبئة النماذج |
| `fill-forms` | تعبئة حقول النماذج |
| `extract` | استخراج النصوص والصور، لقارئات الشاشة مثلًا |
| `assemble` | إدراج الصفحات وتدويرها وحذفها |

والاسم غير المعروف يرمي خطأ: `Unknown PDF permission [printing], expected any of: print, print-highres, copy, modify, annot-forms, fill-forms, extract, assemble.`

ما ينبغي معرفته:

- يشفّر mPDF بخوارزمية RC4 بطول 128 بت، وهي أقوى ما لديه. وهذا يمنع فتح الملف مصادفة، لكنه لا يحمي الأسرار الحقيقية. انظر [الأمان](/ar/guide/security#passwords).
- لا يستطيع Chromium التشفير، فيُنسخ ملف PDF الصادر من Chromium أو Gotenberg بعد ذلك إلى ملف مشفّر بواسطة mPDF، ولهذا يجب تثبيت `mpdf/mpdf`. تبقى الصفحات نصًا، لكن الروابط داخلها تتوقف عن العمل.
- لا تقبل ملفات Word كلمة مرور. استدعاء `->word()` لمستند له كلمة مرور يرمي `Word files cannot take a password; ->password() works for PDF files only.`، فلا يخرج أبدًا ملف مفتوح وأنت تظنه محميًا.

## العنوان والمؤلف {#metadata}

يأتي عنوان ملف PDF، الذي يظهر في شريط عنوان العارض، من أول ما يكون محددًا مما يلي:

1. `->title()` على المستند.
2. عنوان الصفحة في HTML المستند. وتحدده قوالب الفاتورة والتقرير والخطاب والشهادة بلغة المستند: `فاتورة ضريبية INV-2026-1024`، أو `Tax Invoice INV-2026-1024` بالإنجليزية. وفي Blade view خاص بك، مرّر العنوان إلى مكوّن التخطيط، كما في `<x-doc::layout :doc="$doc" title="عقد عمل">`؛ انظر [ملفات Blade و HTML](/ar/guide/views-and-html).
3. العنوان `title` في ملف `template.php` الخاص بالقالب، مثل `Receipt voucher` أو `Payslip`، للقالب الذي ليس لصفحته عنوان خاص بها.

```php
Doc::template('receipt', $data)->locale('ar')->title('سند قبض RV-2026-0315')->pdf();
```

وتحدد `->title()` عنوان ملفات Word أيضًا، وإلا أخذت العنوان `title` من ملف `template.php` (مثل `Tax invoice`).

يجعل mPDF المؤلف اسم الشركة من الهوية (`theme.company.name`، وقيمته الافتراضية `APP_NAME`)، وكذلك ملفات Word. ولا يحدد Chromium مؤلفًا.

## من أين تأتي القيم الافتراضية {#defaults}

يؤخذ كل إعداد من أول مكان يحتويه:

1. استدعاء على المستند: `->paper()` و`->landscape()` و`->margins()` و`->header()` و`->footer()`.
2. ملف `template.php` الخاص بالقالب: `paper` و`orientation` و`margins`، وملفا رأس الصفحة والتذييل. فقالب سند القبض مثلًا مقاسه A5 بالعرض، والشهادة A4 بالعرض.
3. ملف `config/easy-pdf-word.php`: `pdf.paper` و`pdf.orientation` و`pdf.margins`.
4. A4 بالطول، و15 مم من كل جانب.

```php
// config/easy-pdf-word.php
'pdf' => [
    'paper' => 'Letter',
    'orientation' => 'portrait',
    'margins' => [20, 15],
    // ...
],
```

تشرح صفحة [قوالبك الخاصة](/ar/guide/custom-templates) مجلدات القوالب، وتشرح صفحة [الإعدادات](/ar/guide/configuration) كل مفتاح في ملف الإعدادات.
